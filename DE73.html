Q1 Derive State Table and State Diagram for Sequential Circuits 7M ▼

🧠 What is a Sequential Circuit?

Sequential Circuit: A circuit whose output depends on current inputs AND previous state (memory). It uses flip-flops to store state.

Two types: Mealy (output depends on state + input) and Moore (output depends only on state).

📋 Key Terms

  • Present State (PS): Current state stored in flip-flops
  • Next State (NS): State after the clock pulse
  • Output (Z): Produced by the circuit
  • Excitation equations: Boolean equations for NS and output

📌 How to Derive State Table (Steps)

STEP 1 Write down the excitation equations for each flip-flop (JK, SR, D, T) and output from the given circuit.
STEP 2 Assume all possible present states (e.g., for 2 flip-flops: 00, 01, 10, 11) and all input combinations.
STEP 3 For each row, substitute PS and Input into excitation equations → get JK/D/T values.
STEP 4 Use flip-flop truth table to find Next State.
STEP 5 Calculate Output Z from output equation.

Q2 Transition Tables for Asynchronous Sequential Circuits 7M ▼

📖 Asynchronous vs Synchronous

Asynchronous Circuit: No clock! The circuit changes state whenever input changes. It uses latches (SR, D) or simple logic as memory.

Synchronous: All changes happen on clock edge. Asynchronous: Changes happen immediately after input change.

📌 Key Concepts

  • Secondary variables (y): Internal state variables (like flip-flop outputs) — act as memory
  • Excitation variables (Y): Next values of y after input change
  • Stable state: When Y = y (circuit is at rest, no more changes)
  • Unstable state: When Y ≠ y (circuit is still changing)
  • Fundamental mode assumption: Only one input changes at a time

🔧 Transition Table / Flow Table

It shows the next state Y and output Z for each combination of present state (y) and input (x).

  • Circles ⊙ in the table mean stable states (Y = y)
  • Non-circled entries are unstable — the circuit will keep changing until it reaches a stable state

📊 Example: One Secondary Variable (y), One Input (x)

Let excitation equation be: Y = x + y, Output: Z = xy

y\xx=0x=1Z(x=0)Z(x=1)
y=0⊙ 01 (unstable)00
y=10 (unstable)⊙ 101
Read the table: When y=0, x=0 → Y=0+0=0=y → Stable ⊙. When y=0, x=1 → Y=1+0=1≠y=0 → Unstable → moves to y=1.

📊 Internal State Sequence

This is the path the circuit takes through states for a given input sequence.

STEP 1 Start from initial state (say y=0, x=0 — stable)
STEP 2 Change x from 0→1: find Y from table → Y=1 ≠ y=0 (unstable) → move to y=1
STEP 3 At y=1, x=1: Y=1=y → Stable ⊙. Circuit stops here.
STEP 4 Change x from 1→0: Y=0+1=1=y → Stable ⊙ at y=1

⚠️ Race Condition in Async Circuits

Race Condition: When two or more secondary variables try to change simultaneously. If they reach the stable state in different orders → circuit may end up in the wrong state!
  • Non-critical race: Different paths lead to the SAME final stable state — OK ✅
  • Critical race: Different paths lead to DIFFERENT final stable states — BAD ❌
✅ Exam Tip: Always circle stable states in the transition table. State sequence = show each y, Y, and stability step-by-step. 3 marks for table + 4 marks for explanation.
Q3 Hazards in Digital Circuits — Types, Detection, Elimination & Race Avoidance 7M ▼

📖 What is a Hazard?

Hazard: An unwanted, temporary glitch (pulse) in the output of a digital circuit caused by unequal propagation delays of signals through different gate paths.

Hazards cause incorrect outputs for a short time, which is dangerous in asynchronous circuits where there is no clock to filter them.

🔴 Types of Hazards

1. Static Hazard

The output should remain constant (at 0 or 1), but momentarily glitches to the other value due to delay.
  • Static-1 Hazard: Output should stay at 1, but briefly goes to 0 (a 0-glitch)
  • Static-0 Hazard: Output should stay at 0, but briefly goes to 1 (a 1-glitch)

2. Dynamic Hazard

The output should change from 0→1 or 1→0 exactly once, but instead it changes multiple times (e.g., 0→1→0→1) before settling.

Dynamic hazards only occur in multi-level (3+ levels of gates) circuits.

3. Functional Hazard

Caused by the nature of the function itself when two inputs change simultaneously. Cannot be fixed by redesign of the circuit (inherent to the function).

🔍 Detection of Static-1 Hazard (K-map method)

This is the most exam-important method. Use K-map!

STEP 1 Draw the K-map for the Boolean function.
STEP 2 Group 1s as usual (SOP terms).
STEP 3 If two adjacent 1s in the K-map are NOT covered by the same group, a Static-1 Hazard exists between those two cells.

Example Function: F(A,B,C) = Σm(1,2,3,5,6,7)

Fig: K-map showing Static-1 Hazard — adjacent 1s not covered by same group

🛡️ Elimination / Reduction of Hazards

Method 1: Add Redundant Term (K-map method)

STEP 1 Identify the two adjacent 1s not covered by the same group.
STEP 2 Add an extra K-map group that covers BOTH these adjacent 1s.
STEP 3 Add the new product term to the Boolean expression.
Result: The new term acts as a "bridge" — when the circuit transitions between the two groups, the extra term keeps output = 1, preventing the glitch.

Method 2: Use D Flip-Flops (for async circuits)

Adding registers/flip-flops filters out short glitches because they only sample output at clock edges.

Method 3: Increase path delay uniformly

Make all signal paths have equal delays — but this is impractical in real circuits.

🏁 Race Condition Avoidance

Race: Multiple state variables try to change at the same time in async circuits. Solution: Use shared row assignment in state assignment so only ONE variable changes at a time (unit distance / Gray code assignment).
  • Assign states such that only 1 bit changes between consecutive states
  • Use Gray code state assignment: 00→01→11→10
  • Introduce extra states (transition states) if direct Gray code is not possible

Q4 Static and Dynamic Hazards — Methods to Remove from Combinational Circuits 7M ▼

📖 Quick Recap: What is a Hazard?

Hazard: A momentary wrong output (glitch) in a combinational circuit when an input changes, due to different signal path delays.

🔴 Static-1 Hazard (Most Important for Exams)

Definition

Output should stay at 1, but briefly becomes 0 (unwanted LOW pulse).

When does it occur?

In a 2-level AND-OR (SOP) circuit, when a transition takes the circuit between two product terms (AND gates) and neither product term covers that moment.

Example

F = AB + BC

When A=1, B=1, C=1: both terms = 1, output = 1 ✅
Now change A from 1→0 (while B=1, C=1):
— AB goes 0 (delay in A propagating)
— BC should go 1 immediately
— But if AB goes 0 before BC goes 1 → short glitch!

Fig: Adding redundant AND gate (AC) to remove Static-1 Hazard in F = AB + BC

Fix: Add redundant term AC

F = AB + BC + AC ← Hazard-free SOP

Now AC = 1 during the transition (A=1, C=1, B changing), so output stays 1. No glitch! ✅

🔵 Static-0 Hazard

Output should stay at 0, but briefly becomes 1.

Occurs in POS (Product of Sums) circuits. Fix: Add redundant sum term to cover adjacent 0s in K-map.

Fix: Use K-map on 0s (POS simplification) and add bridge sum term

🟡 Dynamic Hazard

Definition

Output changes more than once (e.g., 0→1→0→1) during a single input transition.

Cause

Only possible in circuits with 3 or more levels of gates. Multiple paths reach the output with different delays.

Fix

  • Redesign as a 2-level (SOP or POS) circuit — eliminates dynamic hazards
  • Remove all static hazards from the 2-level circuit first

🗺️ Complete K-map Hazard Removal Procedure

STEP 1 Write the Boolean function and draw its K-map.
STEP 2 Group all 1s using minimum essential prime implicants (standard SOP).
STEP 3 Check if any two adjacent 1s (differing in exactly 1 variable) are NOT covered by a common group.
STEP 4 For each such uncovered adjacent pair, add an extra group (redundant prime implicant) that covers both.
STEP 5 The final expression with all extra groups = Hazard-free SOP.

📝 Summary

Static-1SOP (2-level)1→0→1Add redundant product term (K-map)
Static-0POS (2-level)0→1→0Add redundant sum term

✅ Key Rule: Every pair of adjacent 1s in K-map must be covered by at least ONE common group. If not → Static-1 Hazard exists.
Q5 SRAM Cell — Working, Circuit Diagram and Applications 7M ▼

📖 What is SRAM?

SRAM (Static Random Access Memory): A type of RAM that stores data using a bistable latch (two cross-coupled inverters). It does NOT need refresh. Data is retained as long as power is ON.

"Static" means the data stays without needing periodic refresh — unlike DRAM.

🔧 SRAM Cell Structure (6-Transistor Cell)

The standard SRAM cell uses 6 MOSFETs (transistors):

  • M1, M2 — PMOS load transistors (pull-up)
  • M3, M4 — NMOS driver transistors (pull-down)
  • M5, M6 — NMOS access transistors (controlled by Word Line)

M1–M3 form one inverter, M2–M4 form another. They are cross-coupled to form a bistable latch (SR latch).

Fig: 6-Transistor SRAM Cell — BL=Bit Line, BL'=Complement Bit Line, WL=Word Line

⚙️ Working of SRAM Cell

Storage (Standby Mode)

Word Line (WL) = 0 → Access transistors M5, M6 are OFF → The latch (M1–M4) holds the data stably. No current flows in or out. Q stays at 0 or 1.

Read Operation

STEP 1 Both Bit Lines (BL and BL') are pre-charged to VDD (logic 1).
STEP 2 Word Line WL = 1 → M5 and M6 turn ON.
STEP 3 The latch pulls one bit line low (toward Q or Q'). A sense amplifier detects the small voltage difference and reads the data.

Write Operation

STEP 1 Bit Lines are forced to the data values: BL = new data, BL' = complement.
STEP 2 WL = 1 → M5, M6 ON → strong write drivers overpower the latch and flip it to new state.

📋 Characteristics

🏭 Applications of SRAM

  • CPU Cache memory (L1, L2, L3) — fastest memory in computer
  • Registers in microprocessors
  • Buffer memory in networking equipment
  • FPGA configuration and lookup tables
  • Embedded systems where fast memory is needed
Q6 DRAM Structure and Operation — Compare DRAM vs SRAM 7M ▼

📖 What is DRAM?

DRAM (Dynamic RAM): Stores each bit as charge in a tiny capacitor. It is "dynamic" because the capacitor leaks charge and must be periodically refreshed (every ~64ms) to retain data.

🔧 DRAM Cell Structure (1T-1C Cell)

Each DRAM cell has only 1 transistor + 1 capacitor:

  • Capacitor (C): Stores charge. Charged = 1, Discharged = 0
  • Access transistor (T): NMOS controlled by Word Line (WL)
Fig: DRAM Cell (1T-1C) — 1 Transistor + 1 Capacitor

⚙️ DRAM Operation

Write:

WL = 1 (transistor ON) → Bit Line drives charge into/out of capacitor → Capacitor charges (write 1) or discharges (write 0)

Read:

WL = 1 → capacitor charge shared with bit line → Sense amplifier detects tiny voltage → amplifies → restores data (destructive read, so write-back needed)

Refresh:

Why refresh? The capacitor slowly leaks charge. Every ~64ms, each row must be read and rewritten to prevent data loss.

📖 What is EEPROM?

EEPROM: Electrically Erasable Programmable Read-Only Memory. It can be erased and reprogrammed electrically, byte-by-byte, without removing it from the circuit.

🔧 EEPROM Cell Structure

Each EEPROM cell uses a special transistor called FLOTOX (Floating gate Tunnel Oxide) transistor:

  • Control Gate (CG): Connected to the word line — external control
  • Floating Gate (FG): Completely surrounded by insulator (oxide) — stores charge permanently
  • Tunnel Oxide: Very thin SiO₂ layer between floating gate and drain — allows Fowler-Nordheim tunneling
  • Select Transistor: Connected in series with FLOTOX — used during erase/write to protect unselected cells
Fig: EEPROM FLOTOX Cell — Floating Gate surrounded by insulators traps charge

⚙️ Working Principle: Fowler-Nordheim Tunneling

Electrons can tunnel through the very thin oxide layer when a high voltage is applied. This is called Fowler-Nordheim (FN) Tunneling.

Programming (Write 0):

STEP 1 Apply high positive voltage (~12–20V) on Control Gate.
STEP 2 Strong electric field attracts electrons from substrate through tunnel oxide into Floating Gate.
STEP 3 Floating gate gets negatively charged → threshold voltage of transistor increases → transistor is OFF even when WL = 1 → reads as 0.

Erasing (Write 1):

STEP 1 Apply high positive voltage on Drain (or WL = 0, Drain high).
STEP 2 Electrons tunnel back from floating gate to drain through tunnel oxide.
STEP 3 Floating gate becomes neutral/positive → threshold voltage decreases → transistor conducts normally → reads as 1.

Reading:

Apply normal voltage on WL. If floating gate is charged → transistor OFF → output = 0. If neutral → transistor ON → output = 1.

✅ Advantages of EEPROM

  • Byte-level erasure (erase only what you want)
  • In-circuit programmable (no need to remove chip)
  • Non-volatile (data retained even after power OFF)
  • Endurance: ~1 million erase/write cycles

🏭 Applications

  • BIOS/UEFI firmware storage in computers
  • Smart cards and security tokens
  • Microcontroller configuration storage
  • Calibration data in sensors and instruments
  • Serial number and settings storage in embedded systems
Q8 Design RAM Memory Systems Using Memory ICs 7M ▼

📖 Why Expand Memory?

A single RAM IC has limited capacity. To build a larger memory, we connect multiple ICs. There are two ways: Word Capacity Expansion (more addresses) and Bit Capacity Expansion (more bits per address).

📌 Key Terms

  • Address lines (A): 2ᴬ = number of locations (words)
  • Data lines (D): Number of bits stored per location
  • Chip Select (CS) / Enable (CE): Activates a specific chip
  • Notation: A chip is described as Words × Bits e.g. 1K × 4 = 1024 locations, 4 bits each

📐 Type 1: Word Expansion (More Addresses)

Goal: Increase the number of addressable locations.

Example: Build a 4K × 8 RAM using 1K × 8 chips

Number of chips needed = 4K / 1K = 4 chips

STEP 1 Each chip has 10 address lines (A0–A9) for 1K locations. Connect all A0–A9 to the same address bus.
STEP 2 Use the upper 2 address bits (A10, A11) as chip select signals. Use a 2:4 Decoder to activate one chip at a time.
STEP 3 All data lines are connected to the common data bus (D0–D7).
Fig: Word Expansion — 4 chips of 1K×8 → 4K×8 RAM using 2:4 decoder

📐 Type 2: Bit Expansion (More Data Bits)

Goal: Increase word width (bits per address).

Example: Build a 1K × 16 RAM using 1K × 4 chips

Number of chips needed = 16 / 4 = 4 chips (connected in parallel on data bus)

STEP 1 All chips share the same address lines (A0–A9) — same location is accessed simultaneously.
STEP 2 All chips share the same Chip Select (CS) signal.
STEP 3 Data lines are split: Chip1 → D0–D3, Chip2 → D4–D7, Chip3 → D8–D11, Chip4 → D12–D15.

📊 Formula Summary

Word Expansion: Chips needed = Desired words / Chip words Need: Address decoder for upper bits Bit Expansion: Chips needed = Desired bits / Chip bits No decoder needed (all same CS)

📝 Mixed Expansion Example

Build 4K × 16 using 1K × 4 chips:

  • Word expansion: 4K/1K = 4 groups
  • Bit expansion: 16/4 = 4 chips per group
  • Total chips = 4 × 4 = 16 chips
  • Decoder: 2:4 (for A10, A11)
✅ Exam Formula: Total chips = (Desired Words / Chip Words) × (Desired Bits / Chip Bits)
Q9 ROM Structure and Implementation for Boolean Functions 7M ▼

📖 What is ROM?

ROM (Read-Only Memory): A memory that is permanently programmed at the time of manufacture. You can only read from it — you cannot write during normal operation. It is non-volatile.

🔧 ROM Structure

A ROM has two main parts:

  • Decoder: Converts the input address to one of the 2ⁿ word lines
  • Programmable connections (OR array): Each word line connects to output lines through fuses/transistors to produce the desired output bits

ROM with n input lines and m output lines:
— Decoder generates 2ⁿ product terms (all minterms)
— OR array selects which minterms to include for each output

Fig: ROM Structure — fixed decoder (AND) + programmable OR array

🔣 ROM Implementation of Boolean Functions

Any combinational function can be implemented using ROM by using the truth table directly.

Example: Implement F1(A,B,C) = Σm(1,3,5,7) and F2(A,B,C) = Σm(0,2,4,6)

We need: 3 inputs → 8 locations (8 minterms), 2 outputs

ROM size needed: 8 × 2 ROM

The ROM stores each row as a word. When you apply address A,B,C, the corresponding F1,F2 output is read out immediately.

📋 Steps to Design ROM for Boolean Functions

STEP 1 Write the truth table for all functions together.
STEP 2 Count inputs (n) → ROM needs 2ⁿ addresses. Count outputs (m).
STEP 3 ROM size = 2ⁿ × m bits.
STEP 4 Each output column becomes the ROM's OR array programming (which minterm lines are connected to each output).

✅ Advantages of ROM

  • No minimization needed — use truth table directly
  • Easy to implement multiple functions together
  • Non-volatile, fast read
  • Good for lookup tables, character generators, code converters
ROM size formula: ROM = 2ⁿ × m, where n = input bits, m = output bits. No K-map needed!
Q10 PLA and PAL — Structure, Working, Implementation and Applications 7M ▼

📖 Why PLA/PAL? (The Problem with ROM)

ROM implements ALL 2ⁿ minterms even if most are unused → wastes hardware. PLA and PAL implement only the required product terms → more efficient.

ROMFixed (all minterms)ProgrammableLow

🔶 PLA — Programmable Logic Array

Structure

  • Both AND array and OR array are programmable
  • You choose which inputs go into each AND gate (product term)
  • You choose which product terms go into each OR gate (sum)
  • Typically has: n inputs, k product terms, m outputs
Fig: PLA Structure — programmable AND + OR arrays with 3 inputs, 3 product terms, 2 outputs

PLA Implementation Example

Implement: F1 = AB + BC, F2 = A'B + AC

Product terms needed: AB, BC, A'B, AC → 4 product terms

🔷 PAL — Programmable Array Logic

Structure

  • AND array is programmable (you choose product terms)
  • OR array is fixed (each output OR gate has a fixed set of AND gate inputs)
  • Simpler and faster than PLA, but less flexible

✅ Quick Exam Trick: PLA = both programmable = most flexible. PAL = OR fixed = faster but less flexible. ROM = AND fixed = all minterms = easiest but wastes area.
