Definition of DFA

Formal Definition

A Deterministic Finite Automaton (DFA) is a 5-tuple M = (Q, Σ, δ, q₀, F) where:

  • Q — Finite, non-empty set of states
  • Σ — Finite set of input symbols (alphabet)
  • δ : Q × Σ → Q — Transition function (total function)
  • q₀ ∈ Q — Initial (start) state
  • F ⊆ Q — Set of final (accepting) states

In a DFA, for every state and every input symbol, there is exactly one next state. This is what makes it "deterministic." The machine reads one symbol at a time from left to right and moves to a new state. If after reading the entire string the machine is in an accepting state, the string is accepted.

📝 Key Property

DFA has no ambiguity in transitions. For every (state, symbol) pair, exactly one transition exists. No ε (epsilon) moves are allowed.

DFA for Binary Numbers Divisible by 5

Concept: Divisibility by 5 using Remainders

We track the remainder when dividing by 5. Since binary digits double the current value (like decimal shifts), reading a '0' maps: r → 2r mod 5 and reading a '1' maps: r → (2r+1) mod 5. Remainders can be 0,1,2,3,4 → so we need 5 states.

State Meaning

  • q1 — Remainder = 1
  • q2 — Remainder = 2
  • q3 — Remainder = 3
  • q4 — Remainder = 4

Concept: Minimum State DFA

Definition

A minimum state DFA is an equivalent DFA that accepts the same language but has the smallest possible number of states. Two states are equivalent if they are indistinguishable — that is, for every input string, both states lead to the same acceptance/rejection outcome.

Method: Table Filling Algorithm (Myhill-Nerode Based)

  1. Remove unreachable states — states not reachable from q₀
  2. Mark distinguishable pairs — any pair (p, q) where one is final and other is non-final
  3. Iteratively mark more pairs — if δ(p,a) and δ(q,a) are already marked distinguishable, mark (p,q)
  4. Unmarked pairs are equivalent — merge them into one state
  5. Build new DFA from equivalence classes

Concept: Ternary Number System

Ternary (Base-3) Numbers

Prerequisite: NFA Definition

NFA — Non-deterministic Finite Automaton

An NFA is a 5-tuple M = (Q, Σ, δ, q₀, F) where δ : Q × Σ → 2^Q (the power set). Unlike DFA, from a state on a symbol, the NFA can go to zero, one, or multiple states simultaneously. ε-moves (empty string transitions) may also be allowed.

NFA is more expressive in design but equivalent in power to DFA (both accept exactly the class of Regular Languages). NFAs are easier to construct for pattern-matching problems.

Language Description

Language: L = { w ∈ {a,b}* | the 3rd symbol from the right end of w is 'a' }

In other words, w has the form: w = x · a · y where |y| = 2 (exactly two symbols after the 'a'). So the string must be of length ≥ 3, and position (|w| - 2) must be 'a'.

Examples of strings in L: aaa, aab, aba, abb, baaa, baab, baba, etc.

NFA Construction Strategy

  1. State q0 — Start: Read any number of symbols (stay in q0). Non-deterministically "guess" that the current 'a' is the 3rd from right.
  2. State q1 — We've seen 'a' that we guess is 3rd from right. Read one more symbol (a or b).
  3. State q2 — Read two symbols after the 'a'. One more needed.
  4. State q3 — Final: Read exactly two symbols after the 'a'. String should end here.

Formal Specification

M = (Q, Σ, δ, q₀, F) Q = {q0, q1, q2, q3} Σ = {a, b} Start: q₀ = q0 Final: F = {q3} Transitions: δ(q0, a) = {q0, q1} ← stay in q0 or guess this 'a' is 3rd from right δ(q0, b) = {q0} ← stay and keep reading δ(q1, a) = {q2} ← one more symbol read δ(q1, b) = {q2} ← one more symbol read δ(q2, a) = {q3} ← two more symbols read → accept δ(q2, b) = {q3} ← two more symbols read → accept

DFA Minimization — Table Filling Method

Key Concept

Two states p and q are distinguishable if there exists a string w such that exactly one of δ*(p,w) and δ*(q,w) is a final state. States that are not distinguishable are equivalent and can be merged.

Algorithm Steps

  1. Remove all unreachable states (not reachable from q₀)
  2. Base case (Step 0): Mark all pairs (p,q) where one is final and other is not — they are distinguishable by empty string ε
  3. Inductive step: For each unmarked pair (p,q), for each input symbol a: if (δ(p,a), δ(q,a)) is already marked — then mark (p,q)
  4. Repeat step 3 until no new pairs are marked
  5. All remaining unmarked pairs are equivalent → merge them
  6. Construct the new minimized DFA

Concept: ε-NFA (NFA with Epsilon Moves)

ε-NFA Definition

An ε-NFA is an NFA that allows transitions on ε (empty string). That means the machine can move from one state to another without consuming any input symbol. All three: DFA, NFA, and ε-NFA recognize exactly the same class of languages — Regular Languages.

Key Concept: ε-Closure

📝 ε-Closure

ε-closure(q) = the set of all states reachable from q using only ε-transitions (including q itself). It is the "epsilon reachable" set from q.

Conversion Algorithm: ε-NFA → DFA (Subset Construction)

  1. Compute ε-closure(q₀) — this becomes the start state of DFA
  2. For each DFA state S and each input symbol a: compute ε-closure(δ(S, a)) = ε-closure of union of all transitions on 'a' from states in S
  3. Add this new set as a DFA state if not already present
  4. Repeat until no new states
  5. Any DFA state containing an NFA final state becomes a DFA final state

Overview

This question is about DFA minimization using the partition refinement (equivalence class) method — an alternative to table filling. The idea: start with a coarse partition and refine it until no further splitting is possible.

Myhill-Nerode Equivalence

Two states p and q are k-equivalent if for every string of length ≤ k, they lead to the same accept/reject result. As k → ∞, k-equivalent states become truly equivalent and can be merged.

Partition Refinement Algorithm

  1. Form initial partition P₀ = {F, Q−F} — two groups: final and non-final states
  2. Refine: Split a group G if two states in G have transitions to different groups on some input
  3. Repeat until no group can be split further (stable partition)
  4. Each group becomes one state in the minimized DFA

NFA vs DFA — Key Differences

DFA
  • Exactly one transition per (state, symbol)
  • No ε-moves
  • Easier to implement
  • May need exponentially more states
  • δ : Q × Σ → Q (function)
NFA
  • Zero, one, or many transitions per (state, symbol)
  • ε-moves possible
  • Easier to design
  • Always smaller or equal size
  • δ : Q × Σ → 2^Q (power set)
📝 Rabin-Scott Theorem

Every NFA has an equivalent DFA. If the NFA has n states, the equivalent DFA has at most 2ⁿ states (subset construction). Both accept the same Regular Language.

Subset Construction Algorithm (NFA → DFA)

  1. DFA start state = {q₀} (singleton set containing NFA's start)
  2. For each DFA state S (a set of NFA states) and input a: compute δ_NFA(S, a) = ∪ δ(q, a) for all q in S
  3. This union becomes a new DFA state
  4. Any DFA state containing an NFA final state → DFA final state
  5. Add ∅ (dead state) if needed for completeness

Finite State Transducers (Output Machines)

Unlike DFA/NFA which only accept or reject, Mealy and Moore machines produce an output string for each input. They are called Finite State Transducers (FST) or output automata.

1. Mealy Machine

Definition — Mealy Machine

A Mealy Machine is a 6-tuple M = (Q, Σ, Δ, δ, λ, q₀) where output depends on both current state AND input symbol. Output is associated with transitions.

  • Q — Finite set of states
  • Σ — Input alphabet
  • Δ — Output alphabet
  • δ : Q × Σ → Q — State transition function
  • λ : Q × Σ → Δ — Output function (depends on state + input)
  • q₀ — Initial state

Key Property

Output is produced on each transition. For input string of length n, output string has length n.

2. Moore Machine

Definition — Moore Machine

A Moore Machine is a 6-tuple M = (Q, Σ, Δ, δ, λ, q₀) where output depends only on the current state. Output is associated with states.

  • λ : Q → Δ — Output function (depends only on state)
  • Output string length = input length + 1 (initial state also outputs)
  • Simpler to design; less compact than Mealy

Mealy → Moore Conversion

📝 Conversion Rule

For each Mealy state q that has transitions with different outputs, split it into multiple Moore states — one for each distinct incoming output. Each new state is assigned the output it receives when entered.

  1. For each Mealy state q, look at all transitions leading into q and their outputs
  2. If all transitions into q have output x → create one Moore state q with output x
  3. If transitions into q have different outputs → split into q_x and q_y etc.
  4. The start state of Moore = start state of Mealy with output λ(q₀, first_input), but initial output is typically ε or defined separately
  5. Redirect all transitions accordingly

Conversion of Our Example

In our Mealy machine: q0 is entered from q1 on 'a' (output 0) and self-loop on 'b' (output 0) — all outputs entering q0 are 0. q1 is entered from q0 on 'a' (output 1) and self-loop on 'b' (output 1) — all outputs entering q1 are 1.

No splitting needed! Direct 1-to-1 conversion:

The Moore machine outputs the state's value. For input "aab": p0→p1(out:1)→p0(out:0)→p0(out:0) → output = "100" (Moore outputs n+1=4 with initial state output: "0100").

✅ Conclusion

Mealy and Moore machines are computationally equivalent finite transducers. Mealy is more compact (output on transitions), Moore is simpler conceptually (output on states). Every Mealy machine can be converted to an equivalent Moore machine (possibly with more states) and vice versa.

Introduction

The Myhill-Nerode Theorem is a fundamental result in formal language theory. It provides a necessary and sufficient condition for a language to be regular, and gives us the theoretical foundation for DFA minimization.

Myhill-Nerode Equivalence Relation

For a language L over Σ*, define the relation ≡_L on Σ* as: two strings x and y are Myhill-Nerode equivalent (written x ≡_L y) if and only if for every string z ∈ Σ*, xz ∈ L ⟺ yz ∈ L. In other words, x and y are indistinguishable from the "right" — any continuation z either puts both in L or neither.

Myhill-Nerode Theorem — Statement

📌 Theorem

A language L is regular if and only if the equivalence relation ≡_L has a finite number of equivalence classes. Furthermore, the number of equivalence classes equals the number of states in the minimum DFA for L.

Formal Definition of ≡_L

x ≡_L y iff ∀z ∈ Σ* : (xz ∈ L ↔ yz ∈ L) Right congruence: if x ≡_L y then xa ≡_L ya for all a ∈ Σ Index of ≡_L = number of equivalence classes = states in min-DFA

Three Equivalent Conditions (Theorem)

  1. L is accepted by some DFA
  2. L is the union of some equivalence classes of a right-congruent equivalence relation of finite index
  3. The relation ≡_L itself has finite index (finite equivalence classes)

Example: L = { aⁿbⁿ | n ≥ 0 }

Claim: L is NOT regular (proven by infinite equivalence classes).

Proof of Infinitely Many Classes

Consider strings aⁱ and aʲ where i ≠ j. Choose z = bⁱ:

aⁱ · bⁱ = aⁱbⁱ ∈ L (n = i) aʲ · bⁱ = aʲbⁱ ∉ L (j ≠ i, so j copies of a ≠ i copies of b) ∴ aⁱ ≢_L aʲ for i ≠ j

Since {a, aa, aaa, aaaa, ...} are all in different equivalence classes → infinite classes → L is NOT regular.

Example: L = {w ∈ {a,b}* | w ends in 'ab'}

Claim: L IS regular. Let's find the equivalence classes.

Finding Equivalence Classes

Two strings x and y are equivalent if for ALL z, xz ∈ L iff yz ∈ L. Think of what suffix z is needed:

ClassRepresentativeBehaviourNeeded suffix for L
[ε] = C0ε, b, bb, ...Ends in neither a nor b usefullyNeed "ab" to be added
[a] = C1a, ba, bba, ...Ends in 'a'Need "b" to complete "ab"
[ab] = C2ab, aab, bab, ...Ends in 'ab' — already in LNeed ε (already done)

Verification: C0 (strings not ending in 'a' or 'ab') need suffix "ab". C1 (ending in 'a') need suffix "b". C2 (ending in 'ab') need suffix "ε". These 3 classes are distinct — each needs a different continuation. And any string falls into exactly one class.

// Index of ≡_L = 3 → Minimum DFA has 3 states C0 = [ε] corresponds to state q0 (start) C1 = [a] corresponds to state q1 C2 = [ab] corresponds to state q2 (accepting) // Transition function derived from classes: δ(C0, a) = C1 (now ending in 'a') δ(C0, b) = C0 (still doesn't end in 'a') δ(C1, a) = C1 (still ends in 'a', newer 'a') δ(C1, b) = C2 (was ending in 'a', now append 'b' → ends in 'ab') δ(C2, a) = C1 (now ending in 'a' again) δ(C2, b) = C0 (now ends in 'b' only, not 'ab')

Using Myhill-Nerode for Minimization

The Myhill-Nerode classes are exactly the states of the minimum DFA. States that are Myhill-Nerode equivalent can be merged. The minimum DFA has one state per class.

📝 Practical Use

1) To prove L is NOT regular: show ≡_L has infinitely many classes (Pumping Lemma is a consequence). 2) To minimize a DFA: find the Myhill-Nerode classes — each becomes one state in the minimum DFA.

✅ Conclusion

The Myhill-Nerode theorem elegantly characterizes regularity through right-congruent equivalence classes. It tells us: a language is regular ↔ it has finitely many distinguishable "right-contexts." The number of these classes gives us the exact size of the minimum DFA — making it both a regularity test and a minimization tool.

State Minimization — Complete Method

Goal of Minimization

Given a DFA M, find an equivalent DFA M' with the minimum number of states such that L(M) = L(M'). The minimum DFA is unique up to isomorphism (renaming of states).

Complete Algorithm

  1. Eliminate unreachable states: BFS/DFS from start state. Remove any state not visited.
  2. Create the Distinguishability Table: Mark all pairs (p,q) where exactly one is final.
  3. Propagate marks: If ∃ input 'a' s.t. (δ(p,a), δ(q,a)) is marked → mark (p,q).
  4. Repeat until no new marking.
  5. Merge unmarked pairs into equivalence classes.
  6. Build minimized DFA with one state per class.
