Unit 1 — Number Systems & Codes
Q1 Define binary codes with an example OR Explain signed binary numbers.

Binary Code is a way to represent information (numbers, letters, etc.) using only 0s and 1s.

Example: Decimal 5 = Binary 0101

Common binary codes: BCD, Gray Code, Excess-3, ASCII.

Signed Binary Numbers Signed binary numbers represent positive and negative values. The Most Significant Bit (MSB) is used as the sign bit: 0 = positive, 1 = negative.

Q2 Convert binary numbers into Gray code / Excess-3 code OR Explain Gray code and its significance.

Gray Code: A special binary code where only 1 bit changes between consecutive numbers. This avoids errors during transitions.

Binary to Gray Code conversion rule:

  1. MSB of Gray = MSB of Binary (same)
  2. Each next Gray bit = XOR of current and previous binary bit

Significance: Used in shaft encoders, analog-to-digital converters to avoid glitches.

Excess-3 Code Add 3 (decimal) to the number, then convert to 4-bit binary. Example: Decimal 5 → 5+3=8 → Binary 1000 It is a self-complementing code used in BCD arithmetic.
Q3 Explain 1's complement and 2's complement OR Binary subtraction using complements.

1's Complement: Flip all bits (0→1, 1→0).

Example: 0110 → 1's complement = 1001

2's Complement: 1's complement + 1

Example: 0110 → 1's comp = 1001 → 2's comp = 1010

Subtraction using 2's Complement To find A − B: add A + (2's complement of B) Example: 7 − 3 = 0111 + (2's comp of 0011) 2's comp of 0011 = 1101 0111 + 1101 = 1 0100 → ignore carry → result = 0100 = 4 ✓

Why 2's complement is preferred: It has only one representation of zero, and subtraction becomes addition — simpler hardware.

Unit 2 — Boolean Algebra & Logic Minimization
Q4 Differentiate between SOP and POS forms OR What are SOP and POS forms?

SOP — Sum of Products

  • OR of AND terms
  • Each term = minterm
  • Output = 1 for selected rows
  • Example: F = AB + A'C + BC'

POS — Product of Sums

  • AND of OR terms
  • Each term = maxterm
  • Output = 0 for selected rows
  • Example: F = (A+B)(A'+C)

Simple memory trick: SOP → AND inside, OR outside. POS → OR inside, AND outside.

Q30 Explain don't-care conditions in Karnaugh maps.

Don't-care conditions are input combinations that either never occur OR whose output doesn't matter to us.

They are marked as X (or d) in truth tables and K-maps.

How to use in K-map: You can treat X as 0 or 1 — whichever gives you a larger group (bigger group = simpler expression).

💡 Don't-care conditions help us get a more simplified Boolean expression. We use them greedily — include them in groups only if they help make the group bigger.

Example use: BCD codes — combinations 1010 to 1111 (10–15) never appear in BCD, so they are don't-cares.

Unit 3 — Combinational Circuits
Q5 Define combinational logic / circuits with example.

A Combinational Circuit is a digital circuit where the output depends only on the current inputs — not on past inputs. There is no memory.

Key property: Same input → always same output.

Adder Subtractor Multiplexer Decoder Encoder Comparator

Example: A half adder adds two bits A and B. Output Sum = A⊕B, Carry = A·B. For A=1, B=1 → Sum=0, Carry=1 (always, no memory needed).

Q7 Explain multiplexers OR Implement a 4:1 multiplexer using 2:1 multiplexers.

Multiplexer (MUX): A circuit with many inputs, 1 output. Select lines choose which input to pass to output. Like a channel selector on a TV.

A 4:1 MUX has 4 data inputs (I0–I3), 2 select lines (S1, S0), and 1 output.

Selection logic: S1=0 selects from top MUX; S1=1 selects from bottom MUX. S0 selects between pairs.

Q8 Explain decoder OR Demultiplexer as a decoder with enable input.

Decoder: Takes n-bit input and activates exactly one of 2n output lines. It "decodes" binary to one-hot output.

Example: 2-to-4 decoder — 2 inputs (A, B) → 4 outputs (Y0–Y3). Only one output is HIGH at a time.

DEMUX as Decoder A DeMUX (1-to-many) with the input (Enable) tied to 1 acts as a decoder. The select lines choose which output line gets activated. So: Decoder = DeMUX with Enable=1

Q31 Explain the operation / function of BCD addition.

BCD (Binary Coded Decimal): Each decimal digit (0–9) is stored as 4 bits.

BCD Addition Rule:

  1. Add two BCD digits normally in binary.
  2. If the result is ≤ 9 (≤ 1001), the answer is valid BCD.
  3. If result > 9 (≥ 1010) OR a carry is generated, add 6 (0110) to correct it.
Example: 8 + 7 in BCD 1000 + 0111 = 1111 (= 15 decimal, invalid BCD — > 9) Add 0110: 1111 + 0110 = 1 0101 Result = carry=1, digit=0101 → BCD: 1 5 → 15 ✓

Why add 6? BCD skips 6 invalid codes (1010–1111), so we add 6 to jump over them.

Unit 4 — Sequential Circuits & Flip-Flops
Q9 Explain latch / storage elements / registers.

Latch: A basic memory element that stores 1 bit. It is level-triggered — changes output when the enable/clock is HIGH.

Most basic: SR Latch — Set(S) makes output Q=1; Reset(R) makes Q=0.

Register A group of flip-flops used to store multiple bits together. Example: A 4-bit register stores a 4-bit number. Used in CPU to hold temporary data.

Difference from combinational: Latch has memory — output depends on past inputs too.

Q10 Differentiate between combinational and sequential circuits OR Explain sequential logic.

Combinational

  • Output = f(current inputs only)
  • No memory / no feedback
  • No clock needed
  • Ex: Adder, MUX, Decoder
  • Faster, simpler

Sequential

  • Output = f(inputs + past state)
  • Has memory (flip-flops)
  • Needs clock
  • Ex: Counter, Register, FSM
  • Can do complex tasks

Sequential logic is the foundation of all state machines, CPUs, and memory circuits.

Q11 Define asynchronous / synchronous sequential circuits.

Synchronous

  • All flip-flops share same clock
  • State changes only at clock edge
  • Predictable, easy to design
  • Ex: Synchronous counter

Asynchronous

  • No common clock
  • Changes happen immediately on input
  • Faster but harder to design
  • Ex: Ripple counter
Q12 Explain hazards OR Differentiate between static and dynamic hazards.

Hazard: An unwanted, temporary glitch (wrong output) in a digital circuit caused by unequal propagation delays.

Static Hazard

  • Output should stay constant
  • But briefly glitches (0→1→0 or 1→0→1)
  • Two types: Static-1 and Static-0
  • Fixed by adding redundant gates

Dynamic Hazard

  • Output is supposed to change once
  • But changes multiple times (0→1→0→1)
  • Occurs in multi-level circuits
  • Harder to fix
Essential Hazard Found only in asynchronous sequential circuits. It occurs due to unequal delays in feedback paths and cannot be removed just by adding redundant logic. Must be handled by careful design.
Q13 Define race around condition in JK flip-flop OR Critical race and non-critical race.
Race Around Condition (in JK Flip-Flop) When J=1 and K=1, and the clock pulse is HIGH for too long, the output Q keeps toggling repeatedly. This unstable, unpredictable behavior is called the "race around condition." Fix: Use Master-Slave JK flip-flop OR edge-triggered flip-flop.

Critical Race

  • Final state depends on which variable changes first
  • Different orderings → different final states
  • Causes incorrect circuit behavior
  • Must be avoided

Non-Critical Race

  • Different ordering of changes
  • But all paths lead to the same final state
  • Circuit still works correctly
  • Acceptable in design

Q15 Define propagation delay in digital circuits.

Propagation Delay: The time taken for the output of a gate to respond to a change in input.

Measured in nanoseconds (ns). Lower propagation delay = faster circuit.

Two types: tPHL (High→Low) and tPLH (Low→High).

Effect: Limits maximum operating frequency of a circuit. Cause of hazards.

Q16 Explain positive and negative edge triggering.

Edge-triggered flip-flops only change state at a specific edge (transition) of the clock, not during the entire HIGH or LOW period.

Positive Edge Triggering: Flip-flop responds at 0→1 transition (rising edge). Symbol: triangle at clock input.

Negative Edge Triggering: Responds at 1→0 transition (falling edge). Symbol: triangle + bubble.

Advantage: Edge triggering prevents the race-around condition, unlike level triggering.

Q17 Explain state assignment / state reduction in sequential circuit design.

State Reduction: Process of reducing the number of states in a state machine without changing the circuit's behavior.

Why? Fewer states = fewer flip-flops = simpler, cheaper circuit.

Method: Two states are equivalent if they have same outputs for all inputs AND go to the same next states. Merge them.

State Assignment Assigns binary codes (0,1,00,01,...) to each state. A good state assignment reduces the logic complexity. Poor assignment → complex combinational logic → wasteful. Techniques: Sequential assignment, Gray code assignment, One-hot assignment.

Significance: State assignment directly affects the complexity of the next-state logic, cost, and speed.

Unit 5 — Counters & Registers
Q19 Differentiate between synchronous and asynchronous counters.

Synchronous Counter

  • All FFs share same clock
  • All flip-flops trigger simultaneously
  • Faster (no cumulative delay)
  • More complex wiring
  • No timing errors
  • Ex: 74163

Asynchronous (Ripple) Counter

  • Each FF clocked by previous FF's output
  • Flip-flops trigger one after another
  • Slower (delays add up)
  • Simple wiring
  • Has ripple glitch problem
  • Ex: 7493

Advantage of synchronous: No propagation delay accumulation, so much faster and reliable at high frequencies.

Q20 Explain ring counter.

Ring Counter: A shift register with the output of the last flip-flop connected back to the input of the first. A single 1 "rings" around.

States: 1000 → 0100 → 0010 → 0001 → 1000 (cycles of 4 for 4 flip-flops).

Use: Sequence generators, timing circuits, event distribution. Uses N flip-flops for N states.

Q21 Explain memory OR Differentiate between RAM and ROM.

Memory: Stores binary data (0s and 1s) in digital circuits. Organized as rows (addresses) × columns (data bits).

RAM — Random Access Memory

  • Read and Write both possible
  • Volatile — data lost on power off
  • Used as main memory (temporary)

ROM — Read Only Memory

  • Used for firmware, BIOS

Q23 Differentiate between PAL and PLA.
Programmable Logic Devices (Quick Background) PAL and PLA are ICs where you can program the internal connections to implement any Boolean function. Both have AND array and OR array.

PAL — Programmable Array Logic

  • AND array: programmable
  • OR array: fixed
  • Simpler, faster
  • Less flexible
  • Cheaper

PLA — Programmable Logic Array

  • AND array: programmable
  • OR array: also programmable
  • More flexible
  • Slower (more connections)
  • More expensive

Key difference: In PAL, OR array is fixed. In PLA, both arrays are programmable.

Q28 How many address lines are needed for 8K memory?
Key Formula Number of addressable locations = 2^(number of address lines) So: address lines = log₂(memory size)

8K = 8 × 1024 = 8192 = 213

So we need 13 address lines.

✅ Quick Rule: 1K needs 10 lines, 2K needs 11, 4K needs 12, 8K needs 13, 16K needs 14.
Unit 7 — Logic Families
Q24 Define fan-in and fan-out OR Explain fan-in, fan-out and noise margin.

Fan-in: Maximum number of inputs a logic gate can have. Example: A 4-input AND gate has fan-in = 4.

Fan-out: Maximum number of other gates that a gate's output can drive without losing signal quality. Example: Fan-out of 10 means you can connect 10 gates to the output.

If fan-out is exceeded → output voltage drops → logic errors.

Noise Margin The maximum noise voltage that a circuit can tolerate without changing the output state incorrectly. NMH = VOH(min) − VIH(min) → High-level noise margin NML = VIL(max) − VOL(max) → Low-level noise margin Higher noise margin = more reliable circuit.

Q26 Why is ECL logic faster / better than TTL?

Main reason: In TTL, transistors go into saturation (fully on). Pulling a saturated transistor out of saturation takes time → slow.

In ECL, transistors never saturate. They only switch between the active region (partially on/off). This switching is much faster.

ECL propagation delay: ~1–2 ns TTL propagation delay: ~5–10 ns

Drawback of ECL: High power consumption, needs negative supply voltage (−5.2V), generates more heat.

Use: High-speed computers, telecommunications, when speed is most critical.

Q27 Which logic family consumes the least power?

CMOS (Complementary Metal-Oxide Semiconductor) consumes the least power.

Why? CMOS uses complementary pairs of PMOS and NMOS transistors. Current flows only during switching (0→1 or 1→0). When output is stable, almost no current flows.

💡 CMOS static power ≈ nearly zero. Only dynamic power (during switching) is consumed.

This is why all battery-powered devices (phones, laptops) use CMOS technology.

Q29 What is the role of clock in digital circuits?

A clock is a periodic square wave signal that synchronizes all operations in a digital circuit.

Roles of clock:

  1. Synchronizes all flip-flops to change state at the same time.
  2. Controls the speed of operation (clock frequency).
  3. Prevents race conditions and glitches in sequential circuits.
  4. Divides operations into time slots (clock cycles).

Clock frequency = 1 / time period. Higher frequency = faster circuit but more power.
