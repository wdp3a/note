Q1 Minimize Boolean Functions using K-Map & Implement using NAND/NOR/Basic Gates ▶

What is a K-Map?

A Karnaugh Map (K-map) is a grid-based method to simplify Boolean expressions without algebra. It groups 1s (for SOP) or 0s (for POS) to find the simplest expression.

Rules for Grouping

  • Groups must contain 1, 2, 4, 8, 16… cells (powers of 2)
  • Groups must be as large as possible
  • Cells can be in multiple groups
  • Groups can wrap around edges
  • A Don't Care (X) can be 0 or 1 — use it to make bigger groups

Step-by-Step Example (4-variable)

Minimize: F(A,B,C,D) = Σm(0,1,2,5,8,9,10)

Step 1 — Fill the K-Map

Step 2 — Read the Groups

GroupCells (minterms)Variables that changeSimplified term

Bluem0,m2,m8,m10B changes, D changesB'D'
Purplem1,m5B changesA'CD' (actually A'D... check)
F = B'C' + B'D' + A'B'D (simplified SOP form)

Step 3 — Implement using NAND Gates

SOP can be implemented with NAND gates only using the identity: AB = NAND(NAND(A,B), NAND(A,B)) and A+B = NAND(A',B')

NOR Gate Implementation (for POS)

POS (Product of Sums) is implemented using NOR gates: A+B = NOR(NOR(A,B), NOR(A,B))

Exam Tip: NAND is used for SOP minimization. NOR is used for POS minimization. Both are universal gates — they can implement any Boolean function by themselves.
Q2 Quine-McCluskey (Tabular) Method for Boolean Function Minimization ▶

What is the Quine-McCluskey Method?

It is a table-based algorithm to minimize Boolean functions — especially useful when K-map is difficult (more than 4 variables). It works step-by-step and can be computerized.

Key Terms

  • Minterm: A term where the function = 1
  • Prime Implicant: Largest possible group that can't be combined further
  • Essential Prime Implicant: Covers at least one minterm not covered by others

Q3 De Morgan's Theorem for SOP and POS Forms ▶

De Morgan's Two Laws

De Morgan gave two powerful theorems that connect AND/OR and NOT gates:

Law 1: (A · B)' = A' + B' "NOT of AND = OR of NOTs" Law 2: (A + B)' = A' · B' "NOT of OR = AND of NOTs"
Easy Memory Trick: "Break the bar, change the sign" → change the operation (AND↔OR) and complement each variable.

Proof by Truth Table (2 variables)

ABA·B(A·B)'A'B'A'+B'A+B(A+B)'A'·B'
0001111011
0101101100
1001011100
1110000100

Column (A·B)' = column A'+B' ✓ and column (A+B)' = column A'·B' ✓ — Both theorems proved!

Application to SOP Form

SOP = Sum of Products = OR of AND terms → example: F = AB + CD

To find F' (complement of SOP):

F = AB + CD F' = (AB + CD)' = (AB)' · (CD)' ← Law 2: (X+Y)' = X'·Y' = (A'+B') · (C'+D') ← Law 1: (AB)' = A'+B' This is now in POS form!

Application to POS Form

POS = Product of Sums = AND of OR terms → example: F = (A+B)(C+D)

F = (A+B)(C+D) F' = ((A+B)(C+D))' = (A+B)' + (C+D)' ← Law 1 reversed = (A'B') + (C'D') ← Law 2 applied This is now in SOP form!

Generalized De Morgan's Theorem

For n variables:

( A₁ · A₂ · A₃ · ... · Aₙ )' = A₁' + A₂' + ... + Aₙ' ( A₁ + A₂ + A₃ + ... + Aₙ )' = A₁' · A₂' · ... · Aₙ'

Gate-Level Interpretation

Exam Use: De Morgan's theorem is used to convert SOP↔POS, to simplify logic, and to implement circuits using only NAND or NOR gates.
Q4 Implement XOR Gate using NAND Gates / Universal Realization using NAND Gates ▶

Why NAND is Called Universal Gate?

A universal gate can implement any Boolean function by itself. NAND gate alone can make NOT, AND, OR, NOR, XOR — every other gate.

Part A: Basic Gates from NAND

1. NOT Gate using 1 NAND

2. AND Gate using 2 NANDs

AND(A,B) = NOT(NAND(A,B)) = NAND(NAND(A,B), NAND(A,B))

3. OR Gate using 3 NANDs

OR(A,B) = NAND(A',B') = NAND(NAND(A,A), NAND(B,B))

Part B: XOR Gate using NAND Gates

XOR truth table: A⊕B = 1 when inputs differ.

XOR Boolean expression: A⊕B = AB' + A'B

XOR using NAND gates (4 NAND gates):

Step 1: N1 = NAND(A,B) Step 2: N2 = NAND(A, N1) Step 3: N3 = NAND(B, N1) Step 4: XOR = NAND(N2, N3) ← Final output
Summary: NOT = 1 NAND | AND = 2 NAND | OR = 3 NAND | XOR = 4 NAND
Q5 Realize Boolean Functions using Only NAND Gates ▶

Method: SOP to NAND-NAND

Any SOP (Sum of Products) expression can be directly converted to a 2-level NAND circuit.

Rule: SOP implemented with NAND gates = NAND-NAND circuit (two levels of NAND)
  1. Minimize the Boolean function using K-map → get SOP form
  2. First level: One NAND gate for each product term (AND operation)
  3. Second level: One NAND gate combining all first-level outputs (OR operation using NAND)
  4. If any variable needs complementing, add a NOT (single-input NAND)

Example

Realize: F = AB + BC + AC using only NAND gates

Step 1: SOP is already given: F = AB + BC + AC Step 2: Apply double negation: F = ((AB)' · (BC)' · (AC)')' [De Morgan: A+B+C = (A'B'C')'] Step 3: F = NAND( NAND(A,B), NAND(B,C), NAND(A,C) )

What if inputs are complemented?

If the expression needs A', just add a NOT (= NAND with tied inputs) before that variable.

Exam Tip: To realize F = A'B + AB' (XOR) with NAND, you need 4 NAND gates as shown in Q4.
Q6 Design Full Adder using Half Adders / NAND Gates / OR Gate and Half Adders ▶

What is a Half Adder?

A Half Adder (HA) adds two 1-bit numbers. It has 2 inputs (A, B) and 2 outputs (Sum S, Carry C).

S = A ⊕ B (XOR) C = A · B (AND)

What is a Full Adder?

A Full Adder (FA) adds three 1-bit numbers: A, B, and a Carry-In (Cin). It gives Sum and Carry-Out.

Method A: Using Two Half Adders + OR Gate

  1. HA1 takes inputs A and B → gives S1 = A⊕B and C1 = AB
  2. HA2 takes S1 and Cin → gives S = S1⊕Cin and C2 = S1·Cin
  3. Final Cout = C1 OR C2

A Half Subtractor subtracts two 1-bit numbers A and B. It gives two outputs: Difference (D) and Borrow (B_out). It does NOT handle a Borrow-In.

Q9 BCD Adder using 4-bit Binary Parallel Adders ▶

What is BCD?

BCD (Binary Coded Decimal) represents each decimal digit (0–9) using 4 bits. Valid BCD digits: 0000 to 1001 (0 to 9). Digits 1010 to 1111 (10–15) are invalid in BCD.

Problem with Normal Binary Addition

When two BCD digits are added, the result might exceed 9 (i.e., > 1001 in binary). In that case, the result is wrong in BCD and must be corrected by adding 6 (0110).

When to Add 6?

Add 0110 to the sum if:

  • The result is > 9 (binary sum > 1001), OR
  • There is a Carry-Out from the 4-bit adder

Correction Logic

Let sum = S3 S2 S1 S0 (4 bits from adder), Carry = C4 K = C4 + S3·S2 + S3·S1 If K = 1 → add 0110 and K becomes the carry to next digit If K = 0 → no correction needed

BCD Adder Circuit

  1. First 4-bit binary adder: adds A (BCD digit) + B (BCD digit) → sum S
  2. Correction logic: detect if S > 9 or carry occurred
  3. If correction needed: second 4-bit adder adds S + 0110
  4. Carry-out K goes to next stage

Example: Add BCD 7 + 8

StepValueBinary
A = 770111
B = 881000

15 > 9 → K=1, add 6+6+0110
Corrected Result21 = 2 carry + 51 | 0101
BCD ResultBCD 15 = 0001 0101✓

  • (A > B): 1 when A is greater

Q13 Multiplexed Display Systems and Practical Applications ▶

Why Multiplexed Display?

A 4-digit seven-segment display needs 7×4 = 28 wires if connected directly. Multiplexing reduces this to just 7 segment lines + 4 digit-select lines = 11 wires only.

How Multiplexed Display Works

Only one digit is ON at a time, but they cycle so fast (e.g. 1 kHz) that our eyes see all digits glowing simultaneously. This is called persistence of vision.

  1. Digit 1 is selected (others OFF) → its pattern shown for ~1ms
  2. Digit 2 is selected (others OFF) → its pattern shown for ~1ms
  3. Digit 3 is selected → its pattern shown
  4. Digit 4 is selected → its pattern shown
  5. Cycle repeats >50 times/sec → looks steady to human eye

Block Diagram

Seven-Segment Display Segments

Practical Applications

  • Digital clocks — HH:MM:SS on 6-digit display
  • Calculators — 8-digit seven-segment displays
  • Digital meters — Voltmeter, ammeter panels
  • Score boards — Stadium scoreboards
  • Microcontroller displays — Arduino 4-digit modules
Advantage: Saves I/O pins and wiring. Disadvantage: Each digit is ON only 1/N of the time, so brightness is reduced (compensated by brighter current during ON time).

What is a Flip-Flop?

A flip-flop is a 1-bit memory element. It stores one bit of data and changes its output only at a clock edge.

JK Flip-Flop

JK flip-flop is an improved SR flip-flop that eliminates the invalid state. It has two inputs J (set) and K (reset) plus a clock.

What is an Excitation Table?

An excitation table tells us: "What inputs are needed to take the flip-flop from present state Qn to next state Qn+1?"

It is the reverse of the characteristic table. Used in sequential circuit design.

Q16 Flip-Flop Conversion: JK → D and JK → T Flip-Flop ▶

What is Flip-Flop Conversion?

If we have a JK flip-flop but need a D or T flip-flop, we can add external logic to the JK inputs to make it behave like the desired flip-flop. This is called conversion.

General Method

  1. Write the characteristic table of the target flip-flop (D or T)
  2. Use the excitation table of JK to find required J and K for each transition
  3. Build a table with columns: Qn, Qn+1, Target input (D or T), Required J, Required K
  4. Use K-map to find J and K in terms of the target input and Qn
  5. Draw the circuit: target input → combinational logic → J, K inputs of JK FF

D flip-flop: Qn+1 = D (output follows input)
