⭐ 7 Marks | Code Converters + PLA

What is BCD Code?

BCD (Binary Coded Decimal) represents decimal digits 0–9 using 4 bits. Only 10 combinations out of 16 are valid (0000 to 1001). The rest (1010 to 1111) are don't-care conditions.

What is Excess-3 Code?

Excess-3 is BCD + 3. To get Excess-3 of a decimal digit, add 3 to it and write the 4-bit binary. It is a self-complementing code — 9's complement is obtained by simply inverting the bits.

What is PLA?

A PLA (Programmable Logic Array) has two programmable planes:

  • AND plane — Forms the product terms (minterms)
  • OR plane — Combines product terms to form outputs

PLA is more flexible than ROM because both planes are programmable. It implements SOP (Sum of Products) logic efficiently.

⭐ 7 Marks | Logic Families – TTL

What is a Logic Family?

A logic family is a group of digital ICs that use the same technology, share compatible voltage levels, and can be interconnected. TTL and CMOS are the two most popular logic families.

TTL (Transistor-Transistor Logic)

TTL uses Bipolar Junction Transistors (BJT) as the basic switching element. It is one of the oldest and most popular logic families. Key IC series: 74xx (standard), 74LSxx (Low-Power Schottky), 74Sxx (Schottky).

TTL NAND Gate – Circuit Description

A standard TTL NAND gate has 4 stages:

  1. Multi-emitter transistor (Q1) — Input stage; accepts multiple inputs
  2. Phase splitter transistor (Q2) — Provides complementary signals to output stage
  3. Output transistors (Q3, Q4) — Totem-pole output; Q3 pulls up, Q4 pulls down
  4. Diode (D1) — Speeds up turn-off of Q3

How TTL NAND Gate Works

Case 1: Any Input = LOW (0V)

  • The emitter of Q1 connected to the LOW input is forward biased.
  • Q1 saturates, its collector becomes LOW → Q2 turns OFF
  • Q2 OFF → Q4 OFF, Q3 ON
  • Output is pulled HIGH through Q3 → Output = HIGH (1)

Case 2: All Inputs = HIGH (5V)

  • All emitters of Q1 are at high voltage, so Q1 is in reverse-active mode.
  • Current flows into base of Q2 → Q2 saturates
  • Q2 ON → Q4 ON, Q3 OFF (diode D1 keeps Q3 off)
  • Output is pulled LOW through Q4 → Output = LOW (0)

Exam Tip: Totem-pole output is the key feature of TTL — Q3 pulls output HIGH fast, Q4 pulls it LOW fast. This gives TTL its good speed.
⭐ 7 Marks | Logic Families – CMOS

What is CMOS?

CMOS (Complementary Metal-Oxide-Semiconductor) uses a pair of MOSFETs — one PMOS (P-channel) and one NMOS (N-channel) — connected in a complementary fashion. Key IC series: 4000B (standard CMOS), 74HCxx (High-speed CMOS), 74HCTxx (compatible with TTL).

CMOS Inverter (Basic Building Block)

Understanding the CMOS inverter is the key to understanding all CMOS gates.

Fig: CMOS Inverter — PMOS on top (pull-up), NMOS on bottom (pull-down)

How CMOS Works

When Input = 0 (Low)

  • PMOS: Gate-Source voltage (VGS) is negative → PMOS turns ON (connects output to VDD)
  • NMOS: Gate voltage is 0 → NMOS turns OFF
  • Output is connected to VDD → Output = HIGH

When Input = 1 (High)

  • PMOS: VGS = 0 → PMOS turns OFF
  • NMOS: Gate is high → NMOS turns ON (connects output to GND)
  • Output is connected to GND → Output = LOW
Key Insight: In CMOS, either PMOS or NMOS is ON at a time — never both simultaneously. So there is almost no DC current path from VDD to GND → very low power!

Advantages of CMOS over TTL

  1. Very low power consumption — No static current flows; power only used during switching. TTL always dissipates ~10 mW/gate.
  2. Wide supply voltage range — Works from 2V to 6V. TTL needs exactly 5V ± 5%.
  3. Higher noise margin — About 45% of VDD, much better than TTL's fixed 0.4V.
  4. Higher fan-out — Can drive 50+ CMOS gates vs TTL's 10.
  5. Higher packing density — More gates per chip (smaller transistors).
  6. Better for battery-powered systems — Laptops, phones, watches use CMOS.
Disadvantage of CMOS: CMOS is slower than advanced TTL (like 74S or 74AS) because MOSFETs charge/discharge capacitances. Also sensitive to static electricity (ESD damage).

⭐ 7 Marks | Logic Family Parameters

1. Fan-in

Fan-in is the maximum number of inputs a logic gate can have while still working correctly.

  • More inputs = more load on the circuit driving the gate
  • Example: A 4-input AND gate has a fan-in of 4
  • Typical TTL fan-in: 10 inputs maximum per gate
  • Exceeding fan-in causes incorrect output due to overloading the driving stage

2. Fan-out

Fan-out is the maximum number of gate inputs that one gate output can drive reliably without the voltage levels falling below acceptable thresholds.

  • TTL standard: Fan-out = 10 (one gate can drive 10 TTL inputs)
  • CMOS: Fan-out = 50+ (CMOS inputs draw almost no current)
  • Exceeding fan-out causes output voltage to drop → incorrect logic levels → logic errors

3. Noise Margin

Noise Margin is the amount of noise voltage that can appear on the input of a gate without causing an incorrect output. It is the difference between the guaranteed output voltage and the required input threshold voltage.

Two noise margins:

  • High Noise Margin (NMH) = VOH(min) – VIH(min)
  • Low Noise Margin (NML) = VIL(max) – VOL(max)
ParameterTTL (74xx)CMOS (74HC @ 5V)

Key Point: Higher noise margin = more reliable in noisy environments. CMOS has much better noise margin than TTL.

4. Propagation Delay

Propagation Delay (tpd) is the time it takes for a change at the input of a gate to appear at its output. It is measured in nanoseconds (ns).

  • tPHL = delay when output goes from HIGH to LOW
  • tPLH = delay when output goes from LOW to HIGH
  • Average propagation delay = (tPHL + tPLH) / 2

⭐ 7 Marks | Logic Family Interfacing

Why is Interfacing Needed?

In real systems, you may need to connect TTL and CMOS gates together. The problem is that their voltage levels are not fully compatible:

  • TTL output HIGH (VOH min) = 2.4V
  • CMOS input HIGH (VIH min) = 3.5V (at 5V supply)
  • Problem: TTL output may be 2.4V–5V, but CMOS requires at least 3.5V as a valid HIGH input → Undefined region!

Fig: Voltage incompatibility between TTL output and CMOS input (red = problem zone)

Method 1: TTL → CMOS (Both at 5V)

Use a pull-up resistor (typically 1kΩ – 10kΩ) between TTL output and +5V. This raises the output HIGH level from 2.4V to near 5V, which is a valid CMOS HIGH input.

Method 2: CMOS → TTL (Both at 5V)

CMOS output provides near-VDD (≈5V) HIGH output, which easily satisfies TTL's VIH requirement of 2.0V. The main concern is current: TTL inputs sink 1.6mA each. If CMOS drives many TTL gates, use a buffer/driver IC (like 74HCT series or a transistor) to supply enough current.

Method 3: Using 74HCT Series

The 74HCT (High-speed CMOS TTL-compatible) family is specifically designed for TTL-to-CMOS interfacing. Its input thresholds match TTL levels, while outputs are full CMOS swing. This is the cleanest solution.

Method 4: Open-Collector TTL with Pull-up

Open-collector TTL gates (like 7401) have no internal pull-up. Connecting an external resistor to VDD lets the output swing fully to VDD, making it CMOS-compatible.

1. Binary → Decimal

Multiply each bit by its positional weight (power of 2) and add.

1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
      = 8 + 0 + 2 + 1 = 11₁₀

2. Decimal → Binary

Divide the decimal number by 2 repeatedly. Collect remainders from bottom to top.

13 ÷ 2 = 6  remainder 1  ← LSB
 6 ÷ 2 = 3  remainder 0
 3 ÷ 2 = 1  remainder 1
 1 ÷ 2 = 0  remainder 1  ← MSB

Result (read remainders bottom-up): 13₁₀ = 1101₂

3. Binary → Octal

Group binary digits into groups of 3 from the right. Convert each group to its octal digit.

1 0 1 1 1 0₂
 → 001 | 011 | 110
 →  1  |  3  |  6
 → 136₈

4. Octal → Binary

Replace each octal digit with its 3-bit binary equivalent.

7 5 2₈
→ 111 | 101 | 010
→ 111101010₂

5. Binary → Hexadecimal

Group binary digits into groups of 4 from the right. Convert each group.

1 0 1 1 1 1 0 1₂
→ 1011 | 1101
→  B   |  D
→ BD₁₆

(Hex: A=10, B=11, C=12, D=13, E=14, F=15)

6. Hexadecimal → Binary

Replace each hex digit with its 4-bit binary equivalent.

2 F₁₆
→ 0010 | 1111
→ 00101111₂

7. Decimal → Octal

Divide by 8 repeatedly. Read remainders bottom-up.

100 ÷ 8 = 12  remainder 4  ← LSB
 12 ÷ 8 =  1  remainder 4
  1 ÷ 8 =  0  remainder 1  ← MSB

100₁₀ = 144₈

8. Decimal → Hexadecimal

Divide by 16 repeatedly. Read remainders bottom-up.

255 ÷ 16 = 15  remainder 15 = F  ← LSB
 15 ÷ 16 =  0  remainder 15 = F  ← MSB

255₁₀ = FF₁₆

Part A: Gray Code

What is Gray Code?

Gray Code (also called Reflected Binary Code) is a sequence where only one bit changes between consecutive values. This prevents errors during transitions (no momentary wrong values).

Binary to Gray Code Conversion

Rule: G₃ = B₃ (MSB same). For other bits: Gₙ = Bₙ XOR Bₙ₊₁

Example: Binary = 1011₂
G3 = B3 = 1
G2 = B3 XOR B2 = 1 XOR 0 = 1
G1 = B2 XOR B1 = 0 XOR 1 = 1
G0 = B1 XOR B0 = 1 XOR 1 = 0
Gray Code = 1110

Gray Code to Binary Conversion

Rule: B₃ = G₃ (MSB same). For other bits: Bₙ = Bₙ₊₁ XOR Gₙ

Example: Gray = 1110
B3 = G3 = 1
B2 = B3 XOR G2 = 1 XOR 1 = 0
B1 = B2 XOR G1 = 0 XOR 1 = 1
B0 = B1 XOR G0 = 1 XOR 0 = 1
Binary = 1011

Applications of Gray Code

  • Shaft encoders — Rotary sensors use Gray code so no wrong reading during shaft rotation
  • K-map arrangement — K-map rows/columns use Gray code ordering to ensure adjacent cells differ by 1 bit
  • Digital communication — Reduces errors in transmission
  • Error detection — Cyclic property makes error detection easier

Part B: Excess-3 Code

What is Excess-3?

Excess-3 is formed by adding 3 (0011₂) to each BCD digit. It is a non-weighted, self-complementing code.

Self-Complementing Property

The 9's complement of a digit can be obtained by simply inverting all bits of its Excess-3 code. This makes BCD subtraction easy (no special complementing circuit needed).

DigitBCDExcess-3Complement (9-x)9's Comp Excess-3
00000001191100 (=9+3=12→invert 0011)
40100011151000 (=5+3=8)
70111101020101 (=2+3=5)
91001110000011 (=0+3=3)

Applications of Excess-3 Code

  • BCD arithmetic circuits — Simplifies 9's complement generation (just invert bits)
  • Error detection — No valid code word has all zeros, so all-zero is detectable as error
  • Early computers — Used in IBM 1401 and similar machines
