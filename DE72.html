Step 0 — What is a T Flip-Flop?

A T flip-flop has one input called T (Toggle).

  • If T = 0 → output Q does not change (stays same)
  • If T = 1 → output Q toggles (0→1 or 1→0)

Formula: Q⁺ = T ⊕ Q

Step 1 — What is a JK Flip-Flop?

A JK flip-flop has two inputs J and K:

  • J=0, K=0 → No change
  • J=0, K=1 → Reset (Q=0)
  • J=1, K=0 → Set (Q=1)
  • J=1, K=1 → Toggle

Formula: Q⁺ = J·Q' + K'·Q

Step 2 — Method: Find T in terms of J, K, Q

We want to build JK using T. We need to find: what value of T is needed for every combination of J, K, Q?

💡 Tip
Since T flips when T=1, and stays when T=0, we need T=1 whenever Q has to change.

Key Formula

This expression is implemented using two AND gates and one OR gate. The output T is fed to the T flip-flop. Q and Q' (complement of Q) are fed back from the T flip-flop output.

What is a Shift Register?

A shift register is a group of flip-flops connected in a chain. Data enters one flip-flop at a time and shifts to the next on every clock pulse.

Building Block
Each flip-flop stores 1 bit. A 4-bit shift register = 4 D flip-flops connected in series.

1. Serial-In Serial-Out (SISO)

Data enters serially (1 bit per clock) and leaves serially (1 bit per clock).

  • Input: 1 wire (serial)
  • Output: 1 wire (serial)
  • 4 bits need 4 clock pulses to enter and 4 pulses to exit

SISO Diagram (4-bit)

Fig: 4-bit SISO Shift Register

Operation — Example: Input 1011

Applications of SISO: Data transmission over single wire, delay lines (time delay buffer), serial communication interfaces.

2. Serial-In Parallel-Out (SIPO)

Data enters serially but all bits are available at output simultaneously (parallel).

  • Input: 1 wire
  • Output: 4 wires (one per flip-flop Q)
  • After 4 clock pulses, all 4 bits are on the output at the same time
Fig: 4-bit SIPO Shift Register

Applications of SIPO: Serial-to-parallel data conversion, keyboard input scanning, microcontroller data loading.

3. Bidirectional Shift Register

Data can shift left or right based on a control signal.

  • Control = 1 → data shifts Right
  • Control = 0 → data shifts Left
  • Uses multiplexer (MUX) at input of each flip-flop to select direction
Fig: Bidirectional Shift Register with direction control

Applications of Bidirectional Shift Register:

  • Arithmetic shift operations (multiply/divide by 2)
  • Serial data transmission in both directions
  • Universal shift registers (IC 74194)
  • Ring counters and Johnson counters

What is a Counter?

A counter is a digital circuit that counts clock pulses in a fixed sequence. It is made using flip-flops. Each flip-flop stores one bit.

1. Ripple Counter (Asynchronous Counter)

In a ripple counter, the clock is given only to the first flip-flop. The output of each flip-flop acts as the clock for the next. This causes a ripple effect.

Why "ripple"?
Because the change ripples from FF1 → FF2 → FF3, one after another. There is a time delay.

2-bit Ripple Counter using JK Flip-Flops

Connect J=K=1 (toggle mode) on every flip-flop. Each flip-flop divides frequency by 2.

Fig: 2-bit Ripple Counter

State Sequence (2-bit, counts 0→1→2→3→0)

Clock PulseQ₁Q₀Decimal
0000
1011
2102
3113
4000 (reset)

Disadvantage: Propagation delay (ripple delay) increases with more flip-flops. Not suitable for high-speed circuits.

2. Synchronous Counter

In a synchronous counter, the same clock is given to all flip-flops at the same time. All flip-flops change together — no ripple delay.

Key Difference
Synchronous = all flip-flops clocked simultaneously. Asynchronous (Ripple) = each FF clocked by the previous FF's output.

3-bit Synchronous Counter Design

For a 3-bit synchronous counter, use JK flip-flops. The toggle conditions are:

  • FF₀ (LSB): Toggles every clock. J₀ = K₀ = 1
  • FF₁: Toggles when Q₀ = 1. J₁ = K₁ = Q₀
  • FF₂: Toggles when Q₀ = 1 AND Q₁ = 1. J₂ = K₂ = Q₀·Q₁

What is MOD-10 Counter?

A MOD-10 counter (also called a Decade Counter) counts from 0 to 9, then resets to 0. It has 10 states (0000 to 1001 in BCD).

We need 4 flip-flops (since 2⁴ = 16 > 10). States 10 to 15 are skipped using reset logic.

Reset Logic

When count reaches 10 (1010), Q₃=1 AND Q₁=1. We use this to immediately clear (reset) all flip-flops.

Clear signal: CLR = Q₃ · Q₁

This NAND gate output is connected to the CLR (clear) pin of all flip-flops.

Important
State 1010 appears only momentarily (glitch) before the counter resets. So the counter effectively has 10 stable states: 0–9.

  • Frequency dividers (divide by 10)
  • BCD counters in calculators
  • Event counting in industrial systems

What is a Johnson Counter?

A Johnson Counter (also called Twisted Ring Counter) is a shift register where the complemented (inverted) output Q' of the last flip-flop is fed back to the input of the first flip-flop.

Johnson vs Ring
In a Ring Counter, Q (output) is fed back. In a Johnson Counter, Q' (complement) is fed back. This gives 2n states for n flip-flops (Ring gives only n states).

Introduction

A 3-bit UP/DOWN counter counts from 0 to 7 (UP mode) or from 7 to 0 (DOWN mode), selected by a control input M.

  • M = 1 → Count UP (0 → 1 → 2 → ... → 7 → 0)
  • M = 0 → Count DOWN (7 → 6 → 5 → ... → 0 → 7)

Toggle Conditions

In a JK flip-flop in toggle mode (J=K), the flip-flop toggles when its J=K=1 condition is met.

  • FF₀ (LSB): Toggles every clock → J₀ = K₀ = 1
  • FF₁:
    • UP (M=1): Toggles when Q₀ = 1
    • DOWN (M=0): Toggles when Q₀ = 0 (i.e., Q₀' = 1)
    • Combined: J₁ = K₁ = M·Q₀ + M'·Q₀'
  • FF₂:
    • UP (M=1): Toggles when Q₀=1 AND Q₁=1
    • DOWN (M=0): Toggles when Q₀=0 AND Q₁=0
    • Combined: J₂ = K₂ = M·Q₀·Q₁ + M'·Q₀'·Q₁'

What is Modulo-5 Counter?

A MOD-5 counter counts from 0 to 4 (5 states), then resets to 0. We need 3 flip-flops (2³=8 > 5). States 5,6,7 are not used.

State Sequence

CountQ₂Q₁Q₀
0000
1001
2010
3011
4100
5 → RESET101 ← reset here

Reset Logic

When count = 5 → Q₂=1, Q₁=0, Q₀=1. We detect this state using: CLR = Q₂ · Q₀

Connect Q₂ and Q₀ to a NAND gate. Connect NAND output to CLR (active-low reset) of all flip-flops.

How it works
When Q₂=1 and Q₀=1, NAND output goes LOW → triggers reset → all FFs go to 0. State 5 is seen only for a tiny moment (nanoseconds).

What is a Finite State Machine (FSM)?

An FSM is a sequential circuit with:

  • A fixed number of states
  • Inputs that cause state transitions
  • Outputs produced based on states (and sometimes inputs)

There are two types: Mealy and Moore.

1. Moore Machine

In a Moore machine, the output depends only on the current state (NOT on the input).

  • Output is written inside the state circle
  • Output changes only when the state changes
  • More stable output, no glitches

Moore State Diagram — Sequence Detector for "101"

Fig: Moore Machine — "101" Sequence Detector

2. Mealy Machine

In a Mealy machine, the output depends on both the current state AND the input.

  • Output is written on the transition arrow (not inside state)
  • Output can change immediately when input changes (faster response)
  • Usually needs fewer states than Moore

State Reduction Techniques
7 Marks ▼
state reductionminimizationimplication chartequivalent states

Why Reduce States?

Fewer states → fewer flip-flops → simpler circuit → less cost, less power.

Two states are equivalent if they produce the same output for every input, and their next states are also equivalent.

Method 1: Inspection (Row Matching)

Look at the state table. If two rows have identical outputs AND identical next states → those states are equivalent and can be merged.

Example State Table

StateNext (X=0)Next (X=1)Output
ABC0
BAD0
CBC1
DAD0

Compare rows: B and D have same output (0), same next states when X=0 (A and A), and same next states when X=1 (D and D). So B = D → merge them.

Replace D with B in all entries:

StateNext (X=0)Next (X=1)Output
ABC0
BAB0
CBC1

Result: 4 states reduced to 3 states.

Method 2: Implication Chart

This is a systematic method using a triangular chart (like a half-matrix).

1Create a triangular grid with all state pairs.
2Mark ✗ for pairs with different outputs (they can NEVER be equivalent).
3For unmarked pairs, write the implied pairs that must also be equivalent.
4If an implied pair is ✗, mark the current pair ✗ too.
5Repeat until no new ✗ can be added. Remaining unmarked pairs are equivalent.

Race-Free State Assignment in Asynchronous Sequential Circuits
7 Marks ▼
race conditionrace-freestate assignmentasynchronouscritical race

What is a Race Condition?

In asynchronous circuits, there is no common clock. States change whenever input changes. A race condition occurs when two or more state variables (flip-flops) change at the same time, and the final stable state depends on which one changes first.

Types of Races

  • Non-critical race: Multiple variables change, but they all lead to the same final stable state. This is acceptable.
  • Critical race: Multiple variables change, and depending on the order, the circuit ends up in different states. This causes incorrect behavior. Must be avoided.

Example of Critical Race

Suppose current state = 00 and we want to go to 11. Both y₁ and y₂ must change from 0→1.

  • If y₁ changes first → passes through 10 → might settle at 10 (wrong)
  • If y₂ changes first → passes through 01 → might settle at 01 (wrong)
  • If both change together → reaches 11 (correct)

So 00 → 11 is a critical race. We must avoid it.

Race-Free State Assignment

The goal is to assign binary codes to states such that transitions between states require changing only one bit at a time (adjacent codes). This is called Gray code assignment or adjacent state assignment.

Rules for Race-Free Assignment

1States that have a direct transition between them should have codes that differ by only 1 bit.
2Use Gray code ordering when possible (0→1→3→2 for 2 bits, etc.).
3Add extra intermediate states if necessary to avoid multi-bit transitions.

Example: 4-state assignment

StateBad (binary)Good (Gray code)
A0000
B0101
C1011
D1110

With Gray code, A→B (00→01 ✓), B→C (01→11 ✓), C→D (11→10 ✓), D→A (10→00 ✓). Each transition changes only 1 bit → no races!

Fig: Gray-code adjacent state assignment

Importance

  • Prevents circuit malfunction due to incorrect state transitions
  • Essential in asynchronous circuit design for reliability
  • Reduces glitches and hazards in combinational logic
Steps in Designing Asynchronous Sequential Circuits
7 Marks ▼

What is an Asynchronous Sequential Circuit?

Unlike synchronous circuits (which use a clock), asynchronous circuits change state whenever the input changes. They operate in fundamental mode: only one input changes at a time, and the circuit reaches a stable state before the next input change.

Design Steps

1Problem Statement: Clearly define what the circuit must do. Identify all inputs (x) and outputs (z).
2Primitive Flow Table: Create a flow table showing all stable states and transitions. Each row is a state, each column is an input combination. Stable states are circled.
3State Reduction (Merging): Combine compatible rows in the primitive flow table to reduce the number of states (rows). Use merger diagram or inspection.
4State Assignment (Race-Free): Assign binary codes to states. Use adjacent (Gray-code) assignment to avoid critical races.
5Transition Table: Replace state names with their binary codes to get the transition (excitation) table.
6Derive Excitation Functions: Use K-map to find Boolean expressions for each secondary variable (Y₁, Y₂, etc.).
7Output Function: Derive Boolean expression for output z from the state table using K-map.
8Hazard Check: Check for static-1, static-0, and dynamic hazards. Add bridging terms if needed.
9Circuit Implementation: Draw the final circuit using gates and latches.

Flowchart of Design Process

Fig: Design Steps for Asynchronous Sequential Circuits

Important Notes

  • Use NOR or NAND latches as memory elements (not edge-triggered FFs)
  • Fundamental mode: input changes are assumed to be slow enough for circuit to stabilize
  • Critical races must be avoided using proper state assignment
  • Hazards must be checked in the final Boolean expression

What is a Flow Table?

A flow table is like a state table, but used specifically for asynchronous circuits. It shows:

  • The current state (rows)
  • The input combination (columns)
  • The next state in each cell (stable or unstable)
  • The output for each state

Stable states are circled (the circuit stays there). Unstable states are written plainly (the circuit moves to the next state immediately).

1. Primitive Flow Table

Each row has exactly one stable state. This is the starting point. It is obtained directly from the problem specification by listing all possible conditions.

Example: SR Latch-like behavior

Inputs: S (set) and R (reset). Output: Q

Circled numbers = stable states. Numbers without circles = transitions (move to that state instantly).

2. Merged Flow Table

After state reduction, we merge compatible rows to reduce the number of states. Two rows can be merged if they have no conflicting stable states and no conflicting outputs.

Why Flow Tables are Important

  • Provide a structured, visual representation of all state transitions
  • Help identify all stable and unstable states clearly
  • Enable systematic state reduction (merging)
  • Help identify possible races and hazards
  • Bridge between problem specification and circuit implementation
  • Provide basis for deriving Boolean excitation and output functions
Exam Tip
Always draw both the primitive flow table and merged flow table. Show at least one example of a stable and unstable state. Explain how merging reduces circuit complexity.
