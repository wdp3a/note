Basic Concepts and Automata Theory

Q1 Define alphabet, string and language. 2M
Alphabet (Σ)

A finite, non-empty set of symbols. These are the basic building blocks of any language.

Examples

Σ = {0, 1}  (binary)  |  Σ = {a, b, c}  |  Σ = {A…Z}

String (Word)

A finite sequence of symbols taken from an alphabet Σ. The string with zero symbols is called the empty string ε.

Examples (Σ = {a,b})

ε, a, b, ab, ba, aab, abb, … all are valid strings.

Language (L)

A set of strings over an alphabet Σ. It can be finite or infinite. The set of all possible strings over Σ is written Σ*.

Examples

L = {strings with equal 0's and 1's}  |  L = {aⁿbⁿ | n ≥ 1}

Quick Recall

Alphabet → individual symbols  ·  String → sequence of symbols  ·  Language → set of strings

Q2 Give the definition of Deterministic Finite Automaton (DFA). 2M

Background: An automaton (plural: automata) is an abstract machine that reads an input string and either accepts or rejects it based on a set of rules.

DFA — Deterministic Finite Automaton

A DFA is the simplest type of automaton. It reads a string one symbol at a time, and from any state, on any input symbol, it moves to exactly one next state (no choices → deterministic). At the end, if it is in an accepting state, the string is accepted.

Key Properties

  • Finite number of states.
  • Reads input left to right, one symbol at a time.
  • Exactly one transition per (state, symbol) pair.
  • No ε (empty string) transitions.
  • Accepts if the last state reached is a final/accepting state.

Simple DFA — accepts strings ending with "11"

Q3 Give the mathematical definition of DFA. Differentiate between NFA and DFA. 2M
Mathematical Definition of DFA

A DFA is a 5-tuple: M = (Q, Σ, δ, q₀, F)

  • Q — Finite, non-empty set of states.
  • Σ — Finite input alphabet.
  • δ: Q × Σ → Q — Transition function. Maps (state, symbol) → exactly one next state.
  • q₀ ∈ Q — Initial/start state.
  • F ⊆ Q — Set of final/accepting states.

DFA vs NFA — Comparison

FeatureDFANFA
Full formDeterministic FANon-deterministic FA
TransitionsExactly 1 per (state, symbol)0, 1, or many
ε-transitionsNot allowedAllowed
Transition fn δQ × Σ → QQ × (Σ ∪ {ε}) → 2^Q
Number of statesCan be more (after subset construction)Usually fewer, more compact

Expressive powerEqual — both accept exactly Regular Languages
Key Fact

Every NFA can be converted to an equivalent DFA using the Subset Construction algorithm. They accept the same class of languages.

Q4 What do you mean by ε-Closure in FA? 2M

Background: In an NFA, some transitions happen on the empty string ε — meaning the machine can change state without consuming any input. These are called ε-transitions.

ε-Closure of a State

The ε-Closure of a state q is the set of all states reachable from q using only ε-transitions (zero or more), including q itself.

Formally: ε-closure(q) = {q} ∪ {p | q →ε→ p} (transitively)

How to compute it

  1. Start with the state itself in the set.
  2. Follow every ε-transition from each state in the set.
  3. Add those newly reached states to the set.
  4. Repeat until no new states are added.
Example

If q0 →ε→ q1 →ε→ q2, and q0 →ε→ q3, then:
ε-closure(q0) = {q0, q1, q2, q3}

Why it matters

ε-Closure is used in converting NFA-ε to DFA (subset construction). Each DFA state corresponds to an ε-closure of a set of NFA states.

Q1 Design a regular expression that accepts all strings for Σ = {a,b} containing exactly 2 a's. 2M

We need strings over {a,b} with exactly two a's. The b's can appear anywhere (before, between, or after the a's).

Logic

  • Any number of b's before first 'a': b*
  • First 'a': a
  • Any number of b's between the two a's: b*
  • Second 'a': a
  • Any number of b's after second 'a': b*
Answer

RE = b* a b* a b*

Examples

aa, bab, aba, bbabba, aabb, baab — all accepted.
a, aaa, b, bbb — rejected.

Q2 L1 = {ε}, L2 = {a}, L3 = Ø. Compute L1 L2* ∪ L3*. 2M

Compute step by step:

  1. L2* = {a}* = {ε, a, aa, aaa, …} = set of all strings of a's (a*).
  2. L1 · L2* = {ε} · {ε, a, aa, …} = {ε, a, aa, aaa, …} = a* (concatenating ε with anything = that thing).
  3. L3* = Ø* = {ε} (Kleene star of empty set is always {ε}).
  4. L1 L2* ∪ L3* = a* ∪ {ε} = a* (since {ε} ⊆ a* already).
Final Answer

L1 L2* ∪ L3* = a* = {ε, a, aa, aaa, …}

Key Rule

Ø* = {ε} always. And {ε} · L = L for any language L.

Q3 Write RE for strings where number of a's is divisible by 3, over Σ = {a,b}. 2M

Number of a's divisible by 3 means: 0, 3, 6, 9, … a's. b's can appear anywhere.

Logic

  • Every group of a's must appear in multiples of 3.
  • b's can appear anywhere before, between, or after a's.
  • We group: b* then a b* a b* a (three a's with optional b's between), and repeat this group 0 or more times.
Answer

RE = b* (a b* a b* a b*)*

Verification

0 a's: "bbb" ✓ (divisible by 3).
3 a's: "aaa", "abba" — matched by (ababa* pattern) ✓.
6 a's: apply the group twice ✓.

Q4 Explain in brief about Kleene's Theorem. 2M
Kleene's Theorem

A language is regular if and only if it can be described by a Regular Expression (RE), and it is accepted by a Finite Automaton (FA).

In other words, all three representations are equivalent:

Two parts of the theorem

  • Part 1: Every language defined by a RE can be accepted by some FA.
  • Part 2: Every language accepted by an FA can be described by a RE.
Significance

This theorem established the foundation of formal language theory — connecting machines (FA) with algebraic descriptions (RE).

Q5 State Arden's Theorem. 2M
Arden's Theorem (Statement)

If P and Q are regular expressions over Σ, and P does not contain ε, then the equation:

R = Q + RP

has a unique solution:

R = QP*

Where:

  • R = the unknown language/expression we want to find.
  • Q = strings that don't start with R (base strings).
  • P = the "loop" part (must not contain ε).

Use Case

  • Used to find the Regular Expression from an FA (state equations method).
  • Each state gives a linear equation; solve using Arden's theorem.
Example

If R = b + Ra, then Q = b, P = a → Solution: R = b·a* = ba*

Unit 3

Regular and Non-Regular Grammars

Q1 What do you understand by grammar? 2M
Grammar

A grammar is a set of rules (productions) that define how strings of a language can be generated/derived. It is a formal system for describing languages.

Formally, a grammar is a 4-tuple: G = (V, T, P, S)

  • V — Set of Variables (Non-terminals), e.g., {S, A, B}.
  • T — Set of Terminals (actual symbols of the language), e.g., {a, b}.
  • P — Set of Production rules of the form α → β.
  • S ∈ V — The Start symbol.
Example

G = ({S}, {a,b}, {S → aSb | ε}, S) generates L = {aⁿbⁿ | n ≥ 0}.

Analogy

Think of grammar as the recipe, terminals as ingredients, and the generated strings as the dishes you can cook with those rules.

Q2 Define Context Free Grammar (CFG). 2M
Context Free Grammar (CFG)

A CFG is a grammar where every production rule has the form:
A → α
where A is a single non-terminal (variable), and α is any string of terminals and/or non-terminals (including ε).

The left-hand side is always a single non-terminal — it does not depend on surrounding context. Hence the name: context-free.

Formal Definition

CFG = 4-tuple (V, Σ, R, S) where productions R ⊆ V × (V ∪ Σ)*

Example — CFG for {aⁿbⁿ | n ≥ 1}
S → aSb | ab
TypeProduction Form
Regular GrammarA → aB or A → a
Context Free GrammarA → α (any string)
Context SensitiveαAβ → αγβ (context around A)
Q3 Define Chomsky Hierarchy. 2M

Noam Chomsky classified all formal languages/grammars into a hierarchy of 4 types based on the form of production rules.

TypeGrammarLanguageMachineProduction Rule
Type 0 Unrestricted Recursively Enumerable Turing Machine α → β (any form)
Type 1 Context-Sensitive Context-Sensitive Language Linear Bounded Automata αAβ → αγβ, |γ|≥1
Type 2 Context-Free Context-Free Language Pushdown Automata A → α
Type 3 Regular Regular Language Finite Automaton A → aB or A → a
Key Insight

Type 3 ⊂ Type 2 ⊂ Type 1 ⊂ Type 0. Each type is a proper subset of the type above it. Type 0 is the most powerful and Type 3 the most restricted.

Q4 Is context free language closed under union? If yes, give an example. 2M
Answer

Yes, Context-Free Languages (CFLs) are closed under Union.

Proof (constructive)

If L1 and L2 are CFLs with grammars G1 (start symbol S1) and G2 (start symbol S2), then create a new grammar G with:

New start symbol S with rule: S → S1 | S2

G generates L1 ∪ L2, and G is still a CFG. Hence CFL closed under union.

Example

L1 = {aⁿbⁿ | n≥0} — CFL with grammar: S₁ → aS₁b | ε
L2 = {aᵐbⁿ | m≠n, m,n≥0} — CFL with grammar: S₂ → ... (can be constructed)

Build a new grammar G with fresh start symbol:
S → S₁ | S₂ (plus all rules of G₁ and G₂)
G generates L1 ∪ L2 and is still a CFG. ✓

OperationCFL Closed?
UnionYES ✓
ConcatenationYES ✓
Kleene StarYES ✓
IntersectionNO ✗
ComplementNO ✗
Q5 Remove useless productions: S→AB|ab, A→aA|B|a, B→D|E 2M

A useless production is one that either:

  • Non-generating: Cannot derive any terminal string.
  • Non-reachable: Cannot be reached from the start symbol S.

Step 1 — Find Generating Symbols

A symbol can generate a terminal string if it can eventually produce only terminals.

  • Terminals: a, b → always generating.
  • S → ab (all terminals) → S is generating.
  • A → a (terminal) → A is generating.
  • B → D | E. Neither D nor E appear in any production RHS. So D, E are NOT defined → B cannot generate anything terminal → B is non-generating.
Step 1 Result

Non-generating: B, D, E. Remove all productions containing them.

After removing non-generating:

S → ab (S→AB removed since B is useless) A → aA | a (A→B removed since B is useless)

Step 2 — Find Reachable Symbols from S

  • S → ab: reachable symbols are a, b. No new non-terminals.
  • A is not reachable from S anymore! (S→AB was removed.)
Final Grammar (after removing useless)
S → ab

All other productions (involving A, B, D, E) are useless.

Q6 Construct the CFG for L = {a²ⁿbⁿ | n ≥ 3}. 2M

The language a²ⁿbⁿ means: for every n ≥ 3, the string has 2n a's followed by n b's. Minimum (n=3): aaaaaabbb.

Key idea

  • Each recursive step of S → aaSb wraps 2 more a's on the left and 1 more b on the right — preserving the 2:1 ratio.
  • The base case aaaaaabbb anchors at n=3.
CFG
S → aaSb | aaaaaabbb

Rule S → aaSb adds 2 a's and 1 b each time. Base aaaaaabbb is the smallest valid string (n=3). Together they generate all n ≥ 3.

Derivations
n=3 (base): S ⇒ aaaaaabbb ✓ (6a, 3b) n=4: S ⇒ aaSb ⇒ aa·aaaaaabbb·b = aaaaaaaabbbb ✓ (8a, 4b) n=5: S ⇒ aaSb ⇒ aa·aaSb·b ⇒ aaaa·aaaaaabbb·bb = aaaaaaaaaabbbb ✓ (10a, 5b)
Q7 Write the CFG for regular expression (0+1)*. 2M

The RE (0+1)* means: any binary string (including empty string ε).

Language: L = {ε, 0, 1, 00, 01, 10, 11, 000, …} = all strings over {0,1}.

CFG
S → 0S | 1S | ε

Explanation

  • S → 0S : append a 0 and continue.
  • S → 1S : append a 1 and continue.
  • S → ε : stop (accepting empty / end of string).
Derivation of "010"
S → 0S → 01S → 010S → 010ε = 010 ✓
Q8 Derive the CFG for (a+b)*. 2M

(a+b)* means any string over {a,b} including ε. Same pattern as Q7 but over {a,b}.

CFG
S → aS | bS | ε
  • S → aS: prepend 'a' and recurse.
  • S → bS: prepend 'b' and recurse.
  • S → ε: terminate.
Derivation of "aba"
S → aS → abS → abaS → abaε = aba ✓
Note

This grammar is also a Regular Grammar (right-linear), making it the simplest kind of CFG.

Q9 What are Right Linear and Left Linear grammars? 2M

These are two types of Regular (Type 3) Grammars.

Right Linear Grammar

All productions are of the form:
A → wB or A → w
where w is a string of terminals and B is a non-terminal on the right.

Left Linear Grammar

All productions are of the form:
A → Bw or A → w
where B is a non-terminal on the left and w is a string of terminals.

Q10 Compute the language of G = ({S},{a,b},P,S), P: S→SS|ab|ba|ε 2M

Productions: S → SS | ab | ba | ε

What strings can be generated?

  • S → ε: empty string ε.
  • S → ab: string "ab".
  • S → ba: string "ba".
  • S → SS → ab·ab = abab: concatenation of any two such strings.
  • S → SS → ab·ba = abba
  • S → SSS → ab·ba·ab = abbab and so on…
Language Generated

L(G) = Set of all strings that are concatenations of zero or more "ab" or "ba" blocks. In other words: all strings over {a,b} where equal number of a's and b's, and every prefix has this "balanced block" property.

Sample strings in L(G)

ε, ab, ba, abab, abba, baab, baba, ababab, …

Pattern

L(G) = {w ∈ {a,b}* | w can be split into blocks of "ab" or "ba"}. All strings have even length with equal a's and b's.

Q11 Leftmost derivation for "00110101" in grammar: S→0B|1A; A→0|0S|1AA; B→1|1S|0BB 2M

In leftmost derivation, we always expand the leftmost non-terminal first.

String: 0 0 1 1 0 1 0 1

S ⇒ 0B [S → 0B] — reads '0' ⇒ 00BB [B → 0BB] — reads '0' ⇒ 001SB [B → 1S] — reads '1' ⇒ 0011AB [S → 1A] — reads '1' ⇒ 00110B [A → 0] — reads '0' ⇒ 001101S [B → 1S] — reads '1' ⇒ 0011010B [S → 0B] — reads '0' ⇒ 00110101 [B → 1] — reads '1' = 00110101 ✓
Leftmost Derivation

S ⇒ 0B ⇒ 00BB ⇒ 001SB ⇒ 0011AB ⇒ 00110B ⇒ 001101S ⇒ 0011010B ⇒ 00110101

Remember

Leftmost derivation always replaces the leftmost non-terminal at every step. The sequence of rules used is the leftmost derivation.

Unit 4

Pushdown Automata & CFL

Q1 Discuss briefly about Pushdown Automata (PDA). 2M

Background — What is a Stack?
A stack is a data structure that works on the LIFO (Last In First Out) principle. You can only push (add) or pop (remove) from the top.

Pushdown Automaton (PDA)

A PDA is an NFA with an added stack (unlimited memory). It can push and pop symbols from the stack while reading input. PDA accepts exactly the Context-Free Languages (CFL).

Formally: PDA = 7-tuple (Q, Σ, Γ, δ, q₀, Z₀, F)

  • Q — Finite set of states.
  • Σ — Input alphabet.
  • Γ — Stack alphabet.
  • δ — Transition function: Q × (Σ∪{ε}) × Γ → 2^(Q×Γ*)
  • q₀ — Initial state.
  • Z₀ — Initial stack symbol (bottom of stack).
  • F — Set of final states.

Two Acceptance Modes

  • Accept by final state: End in a final state after reading all input.
  • Accept by empty stack: Stack becomes empty after reading all input.
Classic Example

PDA for {aⁿbⁿ | n≥0}: Push 'a' for each 'a' seen, pop for each 'b'. If stack empty at end → accept.

Q2 What do you mean by Two Stack Pushdown Automata? 2M
Two Stack PDA

A Two Stack PDA is a PDA extended with two stacks instead of one. The machine reads input and can push/pop from either stack independently at each step.

Why is it important?

  • A single-stack PDA accepts Context-Free Languages.
  • A Two-Stack PDA is equivalent in power to a Turing Machine.
  • It can accept Recursively Enumerable languages (Type 0).
Key Point

Two stacks simulate a Turing Machine tape (one stack = left part, other = right part of TM tape). This gives it full computational power.

Q3 Explain pumping lemma for context free language. 2M
Pumping Lemma for CFL

For every CFL L, there exists a constant p (pumping length) such that for every string s ∈ L with |s| ≥ p, s can be split into 5 parts:

s = u v x y z

satisfying these three conditions:

  1. |vy| ≥ 1 (v and y are not both empty).
  2. |vxy| ≤ p (the middle part is not too long).
  3. For all i ≥ 0: u vⁱ x yⁱ z ∈ L (we can "pump" v and y).

Use Case

  • Used to prove a language is NOT context-free.
  • If a language violates the pumping lemma, it cannot be CFL.
Classic Non-CFL Example

L = {aⁿbⁿcⁿ | n≥0} — pumping lemma shows no valid split works for all i. So L is NOT a CFL.

Difference from Regular PL

Regular pumping lemma splits string into 3 parts (xyz). CFL pumping lemma splits into 5 parts (uvxyz) to account for the stack.

Q4 Draw the graphical representation for PDA. 2M

A PDA is drawn like an NFA but with an attached stack and stack operations on transitions.

Transition Notation Explained

Format: input_symbol, stack_top / stack_push Example: a, Z₀/AZ₀ Means: Read 'a', pop Z₀, push AZ₀ (push A on top of Z₀)
Accept Condition

Reach q₂ after consuming full input with stack containing only Z₀ (or empty stack for empty-stack acceptance).

Turing Machines and Recursive Function Theory

Q1 Explain Universal Turing Machine. 2M

Background — Basic TM: A Turing Machine reads/writes on an infinite tape, moves left or right, and accepts or rejects input. It is the most powerful computational model.

Universal Turing Machine (UTM)

A UTM is a special Turing Machine that can simulate any other Turing Machine. It takes as input:
<M, w> = the encoding of TM M + input string w,
and simulates what M does on w.

How it works

  1. The description (encoding) of TM M is written on the tape.
  2. UTM reads M's description to understand its transitions.
  3. UTM simulates M step by step on input w.
  4. If M accepts w → UTM accepts. If M rejects → UTM rejects.
Significance

UTM is the theoretical basis for modern general-purpose computers. Any algorithm on any TM can be run on the UTM — making it "universal."

Q2 What do you mean by basic Turing Machine Model? 2M
Basic Turing Machine (TM)

A Turing Machine is an abstract computing device that consists of an infinite tape and a read/write head controlled by a finite set of states. It is the most powerful model of computation.

Formally: TM = 7-tuple (Q, Σ, Γ, δ, q₀, B, F)

  • Q — Finite set of states.
  • Σ — Input alphabet (⊆ Γ, doesn't include blank B).
  • Γ — Tape alphabet (includes blank symbol B).
  • δ: Q × Γ → Q × Γ × {L, R} — Transition function.
  • q₀ — Start state.
  • B — Blank symbol.
  • F — Set of final/halting states.

At each step the TM:

  1. Reads the symbol under the read/write head.
  2. Writes a new symbol (or same) to the current cell.
  3. Moves the head Left or Right by one cell.
  4. Transitions to a new state.
Q3 What do you understand by the Halting Problem? 2M
The Halting Problem

The Halting Problem asks: "Given a Turing Machine M and input w, will M eventually halt (stop) on w?"
Alan Turing (1936) proved that no algorithm can solve this in general — it is undecidable.

What undecidable means

  • There is no TM that can always correctly answer "yes, M halts" or "no, M loops" for every possible (M, w).
  • Some instances may be answerable, but not all — there's no general algorithm.

Three possibilities for any TM M on input w

  1. M reaches an accept state → Halts and accepts.
  2. M reaches a reject state → Halts and rejects.
  3. M runs forever (infinite loop) → Does not halt.
Key Distinction

Decidable = TM always halts with yes/no.
Semi-decidable = TM halts and says "yes" if true, but may loop if false.
The Halting Problem is semi-decidable but not decidable.

Q4 Explain Halting Problem of Turing Machine. 2M

This is a deeper look at the Halting Problem using proof by contradiction.

Formal Statement

Halting Problem (HP)

HP = {<M, w> | TM M halts on input w}
Is there a decider (TM that always halts) for HP?
Answer: NO.

Proof Sketch (by contradiction)

  1. Assume a TM H exists that decides the halting problem.
    H(<M,w>) = accept if M halts on w; reject if M loops on w.
  2. Construct a new TM D:
    D(<M>) = if H(<M,<M>>) accepts → loop forever; if H rejects → accept.
  3. Ask: what does D do on input <D> itself?
    If D halts → by construction D must loop. Contradiction!
    If D loops → by construction D must halt. Contradiction!
  4. This contradiction means our assumption was wrong → H cannot exist.
Consequence

The Halting Problem is the first example of an undecidable problem. Many other undecidable problems can be proven so by reduction to HP.

Q5 Explain Linear Bounded Automata (LBA). 2M
Linear Bounded Automata (LBA)

An LBA is a restricted Turing Machine where the read/write head can only move within the portion of the tape occupied by the input string. It cannot use more tape space than the input length (linearly bounded).

  • The tape length is bounded by a linear function of the input: at most k × |w| for some constant k.
  • LBA accepts exactly the Context-Sensitive Languages (Type 1).
  • It is more powerful than PDA but weaker than a full TM.

Q6 Explain Multi-Tape Turing Machine. 2M
Multi-Tape Turing Machine

A Multi-Tape TM has k tapes (k ≥ 1), each with its own independent read/write head. At each step, the machine reads all k heads simultaneously, writes to all tapes, and moves each head independently.

Key Properties

  • Tape 1 is usually the input tape (read-only sometimes).
  • Other tapes are used as scratch space or output.
  • More convenient to design algorithms on than single-tape TM.
Critical Theorem

Every k-tape TM can be simulated by a single-tape TM. They are computationally equivalent — Multi-tape TMs do NOT add computational power, only convenience.
