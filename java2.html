UNIT I Introduction, Java Basics & OOP
Q1 Why is Java platform-independent?
Java source code is compiled into bytecode (not machine code) by the Java compiler (javac). This bytecode is platform-neutral and can run on any OS.

The JVM (Java Virtual Machine) installed on each OS reads and executes this bytecode. Since JVM is platform-specific (different JVMs for Windows, Linux, Mac), but bytecode is the same everywhere — Java achieves the principle:

"Write Once, Run Anywhere" (WORA)
Q2 What is an object in Java?
An object is a real-world entity that has state (data/fields) and behavior (methods). It is a runtime instance of a class.

An object has three properties:

  • Identity – unique name/reference
  • State – values stored in instance variables
  • Behavior – actions performed by methods
Car myCar = new Car(); // myCar is an object of class Car
myCar.color = "Red";   // state
myCar.drive();          // behavior
Q3 What is the role of a constructor in a Java class?
A constructor is a special method used to initialize an object when it is created. It has the same name as the class and no return type.

Key points:

  • Called automatically when new is used
  • Can be overloaded (multiple constructors)
  • Java provides a default constructor if none is written
class Student {
    int roll;
    Student(int r) {     // parameterized constructor
        roll = r;
    }
}
Student s = new Student(101); // constructor called

Q6 Explain package and import statement.
A package is a namespace that groups related classes and interfaces. It avoids naming conflicts and provides access control.
An import statement allows using classes from other packages without writing the full class name. 
package com.college.student;  // declares package

import java.util.ArrayList;  // import specific class
import java.util.*;           // import all classes in package

Types: Built-in (java.lang, java.util)   User-defined (com.myapp)

Q7 Why does Java not support multiple inheritance through classes? How is this limitation addressed?
Java avoids multiple inheritance through classes due to the Diamond Problem — when two parent classes have the same method, the child class becomes ambiguous about which to inherit.
Solution: Java supports multiple inheritance through interfaces. A class can implement multiple interfaces, and if both have the same default method, the class must override it — eliminating ambiguity. 
interface A { default void show() {} }
interface B { default void show() {} }
class C implements A, B {
    public void show() { /* must override */ }
}
Q8 Explain wrapper classes and autoboxing/unboxing.
Wrapper classes convert primitive types into objects. Each primitive has a corresponding wrapper in java.lang.

int y = obj;          // Unboxing  (Integer → int)
Q9 Explain significance of static keyword.
The static keyword means a member belongs to the class, not to any object. It is shared across all instances.
  • Static variable – single copy shared by all objects
  • Static method – called without creating an object (Math.sqrt())
  • Static block – runs once when class is loaded
  • Static nested class – class inside class, no outer object needed
class Counter {
    static int count = 0;   // shared by all objects
    Counter() { count++; }
}
Counter c1 = new Counter();
Counter c2 = new Counter();
System.out.println(Counter.count); // 2

Q11 Explain final, finally, and finalize.
final – a keyword used to restrict:
  • final variable → constant (cannot be reassigned)
  • final method → cannot be overridden
  • final class → cannot be extended (e.g., String)
finally – a block in exception handling that always executes, whether exception occurs or not. Used to release resources.
finalize() – a method called by the Garbage Collector before an object is destroyed. Used for cleanup (deprecated in Java 9+).
final int x = 10; // constant

try { /* code */ }
catch(Exception e) { }
finally { // always runs
    System.out.println("Cleanup");
}

protected void finalize() { // GC calls this
    System.out.println("Destroyed");
}
UNIT II Exception Handling, File Handling & Multithreading
Q1 What is the purpose of finally block in Java exception handling?
The finally block always executes after try and catch, regardless of whether an exception occurred or not.

Purpose: Used to perform cleanup operations like closing files, database connections, network sockets, etc.

  • Executes even if exception is not caught
  • Executes even if a return statement is in try block
  • Only skipped if System.exit() is called
try {
    int x = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Caught");
} finally {
    System.out.println("Always runs"); // ← this runs
}

Q3 Describe all keywords used in exception handling.

Java uses 5 keywords for exception handling:

try – Block of code that might throw an exception. Must be followed by catch or finally.
catch – Catches and handles the exception thrown in try block.
finally – Executes always; used for cleanup code.
throw – Used to explicitly throw a specific exception object.
throws – Declares exceptions a method can throw; placed in method signature.
void method() throws IOException {
    try {
        throw new IOException("Error");
    } catch (IOException e) {
        System.out.println(e.getMessage());
    } finally {
        System.out.println("Done");
    }
}
Q4 Describe various states achieved by the thread in its lifecycle.

A Java thread goes through 6 states (as defined by Thread.State):

  • NEW – Thread object created, start() not called yet
  • RUNNABLE – Ready to run or currently executing on CPU (Java's single state for both)
  • BLOCKED – Waiting to acquire a monitor lock (e.g., trying to enter a synchronized block)
  • WAITING – Indefinitely waiting for another thread's signal (wait(), join())
  • TIMED_WAITING – Waiting for a specified time (sleep(ms), wait(ms))
  • TERMINATED (DEAD) – Execution completed or killed
UNIT III Java New Features
Q1 What is a functional interface? Give an example.
A functional interface is an interface with exactly one abstract method (SAM – Single Abstract Method). It can be used with lambda expressions.

Annotated with @FunctionalInterface (optional but recommended). Built-in examples: Runnable, Callable, Comparator.

@FunctionalInterface
interface Greet {
    void hello(String name); // only ONE abstract method
}

// Using lambda expression
Greet g = name -> System.out.println("Hello, " + name);
g.hello("Sushant"); // Hello, Sushant
Q2 Explain forEach() method using lambda expressions.
forEach() is a default method in the Iterable interface (Java 8+). It iterates over each element and applies the given lambda expression (Consumer functional interface).

Syntax: collection.forEach(element -> action)

import java.util.*;

List<String> names = Arrays.asList("Ram", "Shyam", "Geeta");

// Using lambda
names.forEach(n -> System.out.println(n));

// Using method reference (shorthand)
names.forEach(System.out::println);
Q3 Explain sealed classes.
A sealed class (Java 17+) restricts which classes can extend it. Only classes listed in the permits clause are allowed to inherit.

Why use it? To have controlled inheritance — useful for domain modeling and pattern matching.

Each permitted subclass must be declared as: final or sealed or non-sealed

sealed class Shape permits Circle, Rectangle { }

final class Circle extends Shape { }
final class Rectangle extends Shape { }

// Triangle cannot extend Shape → compile error
Q4 Explain switch expressions.
Switch expressions (Java 14+) allow switch to return a value directly. They use the -> arrow syntax and eliminate the need for break.
Old (Statement)New (Expression)
Uses case x: break;Uses case x ->
Cannot return valueCan return value directly
Fall-through possibleNo fall-through
 
int day = 3;
String name = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Other";
};
System.out.println(name); // Wednesday
Q5 Explain yield keyword.
yield (Java 14+) is used inside a switch expression's block body (case x: { ... }) to return a value from that case block.

It is used when you need multi-line logic inside a case and still return a value. Unlike return, yield exits only the switch block.

int x = 2;
int result = switch (x) {
    case 1 -> 10;
    case 2 -> {
        int temp = x * 5;
        yield temp; // returns 10 from this block
    }
    default -> 0;
};
System.out.println(result); // 10

UNIT V Spring Framework & Spring Boot
Q1 What is Spring Boot? How is it different from traditional Spring Framework?
Spring Framework is a comprehensive Java framework for building enterprise applications. It requires significant manual configuration (XML/Java-based).
Spring Boot is built on top of Spring Framework. It eliminates boilerplate configuration using auto-configuration, embedded servers, and starter dependencies.
FeatureSpring FrameworkSpring Boot
ConfigurationManual (XML/Java beans)Auto-configuration via @SpringBootApplication
ServerExternal (Tomcat/JBoss)Embedded (Tomcat built-in)
Setup timeHighMinimal
DeploymentWAR fileExecutable JAR file
Starter POMsNot availableAvailable (spring-boot-starter-web)
ActuatorNot built-inBuilt-in monitoring tools
 
@SpringBootApplication  // replaces 100s of lines of config
public class App {
    public static void main(String[] args) {
        SpringApplication.run(App.class, args);
    }
}

Key point: Spring Boot = Spring + Auto-config + Embedded Server + Starters
